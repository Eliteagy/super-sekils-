# 🧠 Seu 2º Cérebro

**Sistema de organização de conhecimento pessoal**

Bem-vindo ao seu 2º Cérebro! Este sistema vai te ajudar a organizar ideias, projetos e conhecimento de forma eficiente.

---

## 📁 Estrutura (Método PARA)

```
📂 0-Inbox        → Captura rápida (processar depois)
📂 1-Projetos     → Iniciativas com data de conclusão
📂 2-Áreas        → Responsabilidades contínuas
📂 3-Recursos     → Referências e materiais de interesse
📂 4-Arquivos     → Material inativo de referência
```

---

## 🔄 Fluxo de Trabalho

### 1. **Capturar** (Inbox)
- Anote tudo que passar pela cabeça
- Não julgue, apenas capture
- Use atalhos para capturar rápido

### 2. **Processar** (Diário/Semanal)
- Revise sua Inbox
- Mova cada item para a pasta correta
- Delete o que não for útil

### 3. **Organizar**
- Projetos → Ações específicas com prazo
- Áreas → Responsabilidades contínuas
- Recursos → Material de referência
- Arquivos → Guardar para posteridade

### 4. **Revisar** (Semanal)
- Revise projetos ativos
- Atualize áreas de responsabilidade
- Limpe a inbox

---

## 💡 Dicas de Uso

| Hábito | Frequência |
|--------|------------|
| Processar Inbox | Diário |
| Revisar Projetos | Semanal |
| Revisar Áreas | Mensal |
| Limpar Arquivos | Anual |
