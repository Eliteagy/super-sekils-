## 🎯 FRAMEWORK: C.R.E.A.T.O.R.

```
C → CONCEITO (ideia + hook)
R → ROTEIRO (estrutura + fala)
E → EQUIPAMENTO (câmera + áudio + luz)
A → AÇÃO (gravação)
T → TRANSFORMAÇÃO (edição)
O → OUTPUT (exportação)
R → RESULTADOS (análise + otimização)
```

---

### C → CONCEITO

**Antes de tudo:**
- [ ] Qual é o objetivo? (views, seguidores, vendas)
- [ ] Quem é o público?
- [ ] Qual é a promessa única?

**Ferramentas:**
- [[01-Roteiros-Virais#OS 15 HOOKS MAIS PODEROSOS|15 Hooks Virais]]
- [[01-Roteiros-Virais#ESTRUTURAS DE ROTEIRO VIRAL|5 Estruturas]]

---

### R → ROTEIRO

**Elementos:**
```
0-3s:   HOOK (parar scroll)
3-80%:  DESENVOLVIMENTO (reter)
80-95%: PAYOFF (entregar promessa)
95-100%: CTA (chamar ação)
```

**Template:** [[Template-Roteiro-Vídeo]]

---

### E → EQUIPAMENTO

**Mínimo Viável:**
| Item | Opção Barata | Opção Pro |
|------|--------------|-----------|
| Câmera | Telemóvel | Sony A7III |
| Áudio | Boya BY-M1 (€15) | Rode Wireless GO (€200) |
| Luz | Janela | Godox SL-60W |
| Tripé | Suporte telemóvel | Manfrotto |

**Regra:** Áudio > Luz > Câmera

---

### A → AÇÃO (Gravação)

**Checklist:**
- [ ] Bateria carregada
- [ ] Memória disponível
- [ ] Áudio testado
- [ ] Luz testada
- [ ] Enquadramento ok
- [ ] Roteiro visível

**Dicas:**
- Gravar múltiplos takes
- Manter consistência de luz
- Falar mais devagar que o normal

---

### T → TRANSFORMAÇÃO (Edição)

**Fluxo Rápido (30 min):**
1. Importar + organizar (3 min)
2. Corte bruto (5 min)
3. Corte de ritmo (5 min)
4. B-roll (5 min)
5. Texto + legendas (5 min)
6. Áudio + música (5 min)
7. Cor + exportar (5 min)

**Software:**
- Telemóvel: CapCut
- Computador: DaVinci Resolve (grátis) ou Premiere Pro

**Guia:** [[03-Edição-Vídeo]]

---

### O → OUTPUT (Exportação)

**Reels/TikTok/Shorts:**
```
Formato: MP4 (H.264)
Resolução: 1080x1920
FPS: 30 ou 60
Bitrate: 15-20 Mbps
```

**YouTube Longo:**
```
Formato: MP4 (H.264)
Resolução: 1920x1080 ou 4K
FPS: 24, 30 ou 60
Bitrate: 20-50 Mbps
```

---

### R → RESULTADOS (Análise)

**Métricas para Acompanhar:**

| Métrica | Meta Reels | Meta YouTube |
|---------|------------|--------------|
| Hook Rate (3s) | > 70% | > 60% |
| Retenção Média | > 50% | > 40% |
| Retenção Final | > 30% | > 25% |
| Engajamento | > 5% | > 3% |
| CTR (YouTube) | N/A | > 5% |

**Quando analisar:**
- 24h após publicação (primeiros dados)
- 7 dias (tendência clara)
- 30 dias (performance total)

---

**Objetivo:** Aprender + Criar hábito

**Frequência:**
- 3 Reels/TikToks por semana
- 1 YouTube vídeo por mês (opcional)

**Conteúdo:**
```
SEMANA 1:
- [ ] Vídeo 1: "Quem sou eu + o que faço"
- [ ] Vídeo 2: "1 dica rápida do nicho"
- [ ] Vídeo 3: "Erro comum + como evitar"

SEMANA 2:
- [ ] Vídeo 4: "Ferramenta que uso"
- [ ] Vídeo 5: "Antes e depois de cliente"
- [ ] Vídeo 6: "Resposta a pergunta frequente"

SEMANA 3:
- [ ] Vídeo 7: "Processo passo a passo"
- [ ] Vídeo 8: "Mito do nicho desmascarado"
- [ ] Vídeo 9: "Case de sucesso rápido"

SEMANA 4:
- [ ] Vídeo 10: "Lições dos primeiros 30 dias"
- [ ] Vídeo 11: "Previsões/tendências"
- [ ] Vídeo 12: "Convite para seguir jornada"
```

---

### Plano Intermédio (30-90 Dias)

**Objetivo:** Crescer audiência + autoridade

**Frequência:**
- 5-7 Reels/TikToks por semana
- 1 YouTube vídeo por semana
- 1 YouTube Short por dia (clip de longo)

**Conteúdo:**
- 70% educativo (valor)
- 20% entretenimento (viral)
- 10% promoção (vendas)

---

### Plano Avançado (90+ Dias)

**Objetivo:** Escalar + Monetizar

**Frequência:**
- 10+ Reels/TikToks por semana
- 2 YouTube vídeos por semana
- Lives semanais (opcional)

**Estratégia:**
- Sistema de batch (gravar 10 vídeos/dia)
- Equipa/freelancers para edição
- Múltiplos formatos do mesmo conteúdo

## 🔄 SISTEMA DE BATCH PRODUCTION

---

### Como Gravar 10 Vídeos em 1 Dia

**Preparação (1 dia antes):**
```
- [ ] Escrever 10 roteiros
- [ ] Separar por tipo de plano
- [ ] Preparar cenários
- [ ] Carregar baterias
- [ ] Limpar memória
```

**Dia de Gravação:**
```
MANHÃ (3 horas):
09:00 - 09:30 → Setup + testes
09:30 - 10:30 → Gravar Vídeos 1-3 (mesmo cenário)
10:30 - 10:45 → Pausa
10:45 - 11:45 → Gravar Vídeos 4-6 (mudar cenário)
11:45 - 12:00 → Mudar para cenário 3

TARDE (2 horas):
14:00 - 15:00 → Gravar Vídeos 7-9
15:00 - 15:30 → Gravar Vídeo 10 + B-roll extra
15:30 - 16:00 → Organizar ficheiros
```

**Pós-Gravação:**
```
- [ ] Backup de todos os ficheiros
- [ ] Nomear corretamente
- [ ] Criar pasta para cada vídeo
- [ ] Iniciar edição (ou delegar)
```

## 📈 MÉTRICAS DE SUCESSO

---

### Por Fase de Crescimento

**Fase 1: 0-1.000 Seguidores**
- Foco: Consistência + Aprendizado
- Meta: 3-5 vídeos/semana
- KPI: Hook rate, retenção inicial

**Fase 2: 1.000-10.000 Seguidores**
- Foco: Otimização + Viralização
- Meta: 5-7 vídeos/semana
- KPI: Partilhas, retenção total

**Fase 3: 10.000-100.000 Seguidores**
- Foco: Autoridade + Monetização
- Meta: 7-10 vídeos/semana
- KPI: Conversão, revenue

**Fase 4: 100.000+ Seguidores**
- Foco: Escala + Equipa
- Meta: 10+ vídeos/semana
- KPI: Margem, LTV

## ⚠️ ERROS COMUNS

| Erro | Impacto | Como Evitar |
|------|---------|-------------|
| Hook fraco | 80% scroll antes de 3s | Testar 5 hooks diferentes |
| Áudio mau | Vídeo ignorado | Testar áudio antes de gravar |
| Sem CTA | Zero ação do viewer | Sempre pedir ação específica |
| Inconsistência | Algoritmo ignora | Criar calendário realista |
| Perfeccionismo | Nunca publica | Feito > perfeito |
| Copiar outros | Sem autenticidade | Inspirar-se, não copiar |
| Ignorar analytics | Sem otimização | Analisar semanalmente |
