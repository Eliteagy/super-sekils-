# Onboarding de Clientes Premium

**Categoria:** #onboarding #gestão #clientes
**Nível:** Intermediário
**Fonte:** Mentoria 2026-03-29

---

## 💡 Ideia Principal

> **Os primeiros 30 dias definem o relacionamento.** Um onboarding estruturado cria confiança, reduz ansiedade e estabelece expectativas claras.

---

## 📊 TIMELINE DE ONBOARDING (30 Dias)

```
DIA 0     → Contrato assinado + Pagamento recebido
DIA 1     → Kickoff meeting + Briefing completo
DIA 2-3   → Pesquisa + Estratégia inicial
DIA 4-5   → Aprovação da estratégia
DIA 6-10  → Produção Conteúdo (Batch 1)
DIA 11-14 → Revisão + Aprovação
DIA 15-20 → Produção Conteúdo (Batch 2) + Início publicação
DIA 21-25 → Otimização + Primeiros resultados
DIA 26-30 → Review mensal + Planeamento mês 2
```

---

## 🎯 DIA 0: CONTRATO + PAGAMENTO

### Checklist Pré-Onboarding:

- [ ] Contrato assinado por ambas as partes
- [ ] Primeiro pagamento recebido (50% upfront ou mês 1 completo)
- [ ] Dados de faturação recolhidos
- [ ] Contacto de emergência definido
- [ ] Grupo de WhatsApp/Slack criado

### E-mail de Boas-Vindas:

**Assunto:** Bem-vindo à [Agência]! 🚀

```
Oi [Nome],

Seja bem-vindo(a)! Estamos entusiasmados por trabalhar contigo.

O que acontece agora:

1. ✅ Pagamento confirmado — Obrigado!
2. 📅 Kickoff meeting agendada para [data/hora]
3. 📋 Briefing prévio — Envia até [data]
4. 🎬 Produção começa [data]

Próximos passos:
- Preenche o briefing (link em baixo)
- Prepara acesso às redes sociais
- Reúne material existente (logos, fotos, vídeos)

Links importantes:
- Briefing: [link]
- Grupo WhatsApp: [link]
- Pasta Google Drive: [link]

Qualquer dúvida, estou por aqui!

[Teu nome]
```

## 📋 DIA 1: KICKOFF MEETING (60 min)

### Agenda da Reunião:

| Tempo | Tópico | Objetivo |
|-------|--------|----------|
| 0-5 min | Quebra-gelo | Criar rapport |
| 5-15 min | Apresentação da equipa | Quem trabalha no projeto |
| 15-25 min | Revisão do briefing | Confirmar objetivos |
| 25-40 min | Expectativas | Alinhar o que cada parte espera |
| 40-50 min | Processo de trabalho | Como vão trabalhar juntos |
| 50-60 min | Próximos passos + Q&A | Fechar com ações claras |

---

### Perguntas do Briefing Completo:

**Sobre o Negócio:**
1. "O que faz a vossa empresa?"
2. "Qual é o vosso produto/serviço principal?"
3. "Qual é o ticket médio?"
4. "Quantas vendas fazem por mês atualmente?"

**Sobre o Cliente Ideal:**
5. "Quem é o vosso cliente ideal? Descreve em detalhe."
6. "O que motiva este cliente a comprar?"
7. "Quais são as objeções mais comuns?"

**Sobre a Concorrência:**
8. "Quem são os vossos principais concorrentes?"
9. "O que vos diferencia deles?"
10. "Quem faz bem o trabalho nas redes sociais (no vosso setor)?"

**Sobre Objetivos:**
11. "O que queres alcançar com este projeto?"
12. "Como medimos sucesso? Quais são as KPIs?"
13. "Qual é o prazo para ver resultados?"

**Sobre Brand:**
14. "Qual é o tom de voz da marca?"
15. "Há alguma palavra/frase que NÃO devemos usar?"
16. "Tens exemplos de conteúdo que gostas?"

**Sobre Logística:**
17. "Quem aprova o conteúdo?"
18. "Qual é o tempo típico de aprovação?"
19. "Há alguma restrição legal/compliance?"
20. "Podemos marcar conteúdo com antecedência?"

## 📊 DIA 2-3: PESQUISA + ESTRATÉGIA

### Pesquisa Interna (Agência):

**Análise da Concorrência:**
- [ ] Identificar 3-5 concorrentes diretos
- [ ] Analisar conteúdo que funciona para eles
- [ ] Identificar gaps/oportunidades

**Análise do Cliente Ideal:**
- [ ] Criar persona detalhada
- [ ] Identificar dores, desejos, objeções
- [ ] Mapear jornada de compra

**Análise da Marca:**
- [ ] Revisar identidade visual existente
- [ ] Analisar tom de voz atual
- [ ] Identificar elementos de diferenciação

---

### Documento de Estratégia (Entregar Dia 3):

**Estrutura:**

```
# ESTRATÉGIA DE CONTEÚDO — [CLIENTE]

## 1. Resumo Executivo
- Objetivo principal: [ex: gerar 20 leads/mês]
- KPIs: [ex: reach, engagement, leads, vendas]
- Timeline: [ex: 3 meses para resultados significativos]

## 2. Público-Alvo
- Persona: [nome, idade, profissão, dores, desejos]
- Onde está online: [plataformas, horários]
- O que consome: [tipos de conteúdo]

## 3. Pilares de Conteúdo
- Pilar 1: [ex: Educação — 40%]
- Pilar 2: [ex: Prova Social — 30%]
- Pilar 3: [ex: Vendas — 20%]
- Pilar 4: [ex: Behind-the-scenes — 10%]

## 4. Frequência de Publicação
- Instagram: [ex: 5 posts/semana + 10 stories/dia]
- LinkedIn: [ex: 3 posts/semana]
- TikTok: [ex: 3 vídeos/semana]

## 5. Tom de Voz
- [ex: Profissional mas acessível, direto, sem jargão]

## 6. Exemplos de Conteúdo
- [3-5 exemplos visuais de posts propostos]

## 7. Próximos Passos
- [O que o cliente precisa aprovar]
- [Timeline de produção]
- [Data de início]
```

```
- KPIs: [reach, engagement, leads]

2. Enviar feedback até [data]

[Teu nome]
```

## 🎬 DIA 6-10: PRODUÇÃO DE CONTEÚDO (BATCH 1)

### Checklist de Produção:

- [ ] Criar 10-15 posts (Instagram + LinkedIn)
- [ ] Criar 5-8 vídeos curtos (Reels/TikTok)
- [ ] Escrever captions para cada post
- [ ] Selecionar/criar hashtags
- [ ] Agendar no ferramenta (Buffer, Later, etc.)

### Template de Conteúdo:

```
POST #1
---------
Tipo: [Carrossel/Single/Reel]
Pilar: [Educação/Prova Social/Vendas/BTS]
Copy: [Texto completo]
Visual: [Descrição ou arquivo anexo]
Hashtags: [#lista #de #hashtags]
CTA: [Call-to-action]
Data prevista: [DD/MM]
```

---

## 👀 DIA 11-14: REVISÃO + APROVAÇÃO

### E-mail de Envio para Aprovação:

**Assunto:** Conteúdo para Aprovação — Batch 1

```
Oi [Nome],

Segue o primeiro batch de conteúdo para aprovação.

Total: [X] posts + [Y] vídeos
Período: [DD/MM] a [DD/MM]

Link para revisão: [Google Drive/Later/Buffer]

Deadline de aprovação: [DD/MM]

Notas:
- [Destacar algum post específico]
- [Pedir feedback sobre tom/estilo]

Aguardo feedback!

[Teu nome]
```

---

### Processo de Revisão:

**Se o cliente aprovar:**
- [ ] Confirmar receção
- [ ] Agendar posts
- [ ] Iniciar Batch 2

**Se o cliente pedir alterações:**
- [ ] Listar todas as alterações
- [ ] Priorizar (crítico vs. nice-to-have)
- [ ] Implementar alterações
- [ ] Reenviar para aprovação final

**Se o cliente não responder:**
- [ ] Follow-up Dia 1
- [ ] Follow-up Dia 3
- [ ] Ligar se necessário

---

## 🚀 DIA 15-20: BATCH 2 + INÍCIO PUBLICAÇÃO

### Checklist:

- [ ] Produzir Batch 2 (mesmo processo do Batch 1)
- [ ] Agendar todos os posts
- [ ] Confirmar primeiros posts publicados
- [ ] Monitorizar comentários/engagement

## ⚠️ PROBLEMAS COMUNS NO ONBOARDING

| Problema | Causa | Solução |
|----------|-------|---------|
| Cliente não aprova conteúdo | Expectativas não alinhadas | Revisar briefing, pedir exemplos |
| Cliente demora a aprovar | Não prioriza | Definir deadline claro no contrato |
| Cliente pede muitas alterações | Não confia no processo | Mostrar dados, case studies |
| Cliente não responde | Ocupado/desinteressado | Follow-up consistente, ligar |
| Resultados lentos | Expectativas irreais | Reeducar sobre timeline real |
