# 🎬 Roteiros para Vídeos Virais

**Categoria:** #conteúdo #vídeo #viral #roteiro
**Nível:** Fundamental

---

## 💡 Ideia Principal

> **Um vídeo viral não é sorte — é estrutura.** Segue padrões psicológicos que mantêm atenção e geram partilha.

---

## 📊 A FÓRMULA DO VÍDEO VIRAL

```
VÍDEO VIRAL = HOOK (3s) + RETENÇÃO + PAYOFF + CTA
```

| Elemento | Duração | Objetivo |
|----------|---------|----------|
| **Hook** | 0-3s | Parar o scroll |
| **Retenção** | 3-80% | Manter atenção |
| **Payoff** | 80-95% | Entregar promessa |
| **CTA** | 95-100% | Chamar para ação |

---

### Hook #1: "Isto Vai Mudar A Tua Vida..."
```
"Isto vai mudar a forma como [fazes X] para sempre."
```
**Por que funciona:** Promessa de transformação imediata


## 📐 ESTRUTURAS DE ROTEIRO VIRAL

---

### Estrutura #1: PROBLEMA → AGITAÇÃO → SOLUÇÃO (PAS)

**Duração:** 30-60 segundos

```
0-3s:  HOOK — "Estás a perder dinheiro com [problema]?"
3-10s: PROBLEMA — Descreve o problema claramente
10-25s: AGITAÇÃO — Mostra consequências, dói mais
25-50s: SOLUÇÃO — Apresenta a tua solução
50-60s: CTA — "Segue para mais" ou "Comenta X"
```

**Exemplo Prático:**
```
HOOK: "Estás a perder €500/mês sem saber."

PROBLEMA: "A maioria dos negócios locais não sabe
           quanto gastam em marketing inútil."

AGITAÇÃO: "No final do ano, são €6.000 perdidos.
           Dinheiro que podias ter investido em
           algo que funciona."

SOLUÇÃO: "Cria uma spreadsheet simples. Regista
          cada euro gasto. No fim do mês, corta
          o que não traz retorno."

CTA: "Queres o template? Comenta 'TEMPLATE'."
```

---

### Estrutura #2: ANTES → DEPOIS → PONTE

**Duração:** 30-90 segundos

```
0-3s:  HOOK — Mostra o resultado final
3-15s: ANTES — Como era a vida antes
15-30s: DEPOIS — Como é a vida agora
30-75s: PONTE — O processo/método usado
75-90s: CTA — Chamada para ação
```

**Exemplo Prático:**
```
HOOK: [Mostra resultado: €10.000/mês]

ANTES: "Há 6 meses faturava €500/mês.
        Trabalhava 12h/dia, stressado."

DEPOIS: "Agora faturro €10.000/mês.
         Trabalho 4h/dia, sem stress."

PONTE: "O que mudei:
        1. Subi preços de €200 para €1.000
        2. Foquei em 1 nicho apenas
        3. Criei sistema de indicações
        4. Automatizei outreach"

CTA: "Queres o mesmo? Link na bio."
```

---

### Estrutura #3: LISTA (3-5-7 Coisas)

**Duração:** 45-90 segundos

```
0-3s:  HOOK — "X coisas que [assunto]"
3-10s: Intro rápida
10-20s: Item #1 (mais fraco)
20-35s: Item #2 (médio)
35-55s: Item #3 (melhor/mais importante)
55-90s: CTA + Bónus
```

**Exemplo Prático:**
```
HOOK: "3 ferramentas que uso para criar
       conteúdo em 1h/semana."

#1: "CapCut — edito vídeos em 10 minutos"
#2: "Notion — planeio todo o conteúdo"
#3: "OpusClip — transformo vídeos longos
     em 10 reels automáticos"

CTA: "Qual vais experimentar primeiro?
      Comenta abaixo."
```

---

### Estrutura #4: STORYTELLING (Jornada do Herói)

**Duração:** 60-180 segundos

```
0-5s:  HOOK — "Quase desisti disto..."
5-15s: MUNDO NORMAL — Como era antes
15-25s: CHAMADO — O que mudou/começou
25-40s: DESAFIOS — O que correu mal
40-55s: MENTOR/VITÓRIA — O que aprendeu/mudou
55-80s: RESULTADO — Onde está agora
80-90s: CTA — "Tu podes também"
```

---

### Estrutura #5: TUTORIAL PASSO A PASSO

**Duração:** 60-120 segundos

```
0-3s:  HOOK — "Como [fazer X] em [Y] passos"
3-10s: Promessa do resultado
10-20s: Passo 1 (básico)
20-40s: Passo 2 (intermédio)
40-60s: Passo 3 (avançado)
60-80s: Dicas extras/erros comuns
80-90s: CTA
```

## 🎬 PLANOS DE CÂMERA PARA VÍDEOS

---

### Para Reels/TikTok (Vertical 9:16)

| Plano | Enquadramento | Quando Usar |
|-------|---------------|-------------|
| **Close-up** | Rosto ocupa 80% ecrã | Hooks, emoção, confissões |
| **Medium Shot** | Cintura para cima | Talking head, tutoriais |
| **Full Body** | Corpo inteiro | Danças, transições, before/after |
| **Over the Shoulder** | Por cima do ombro | Ecrãs, computadores, trabalho |
| **POV** | Ponto de vista | "Um dia comigo", processos |
| **Top Down** | Vista de cima | Mesas, comida, unboxing |

---

### Para YouTube (Horizontal 16:9)

| Plano | Enquadramento | Quando Usar |
|-------|---------------|-------------|
| **Extreme Close-up** | Olhos/boca apenas | Ênfase dramática |
| **Close-up** | Rosto completo | Conversas, emoção |
| **Medium Shot** | Cintura para cima | Standard YouTube |
| **Medium Wide** | Joelhos para cima | Grupos, movimento |
| **Wide Shot** | Corpo inteiro + ambiente | Contexto, localização |
| **Extreme Wide** | Paisagem | Estabelecer cenário |

## 📐 REGRA DOS TERÇOS

```
Divide o ecrã em 3x3 (9 quadrados):

+---+---+---+
|   |   |   |
+---+---+---+
|   | X |   |  ← Pontos de poder (X)
+---+---+---+
|   |   |   |
+---+---+---+

Posiciona o sujeito nos pontos X ou nas linhas.
Nunca no centro exato (fica estático/chato).
```

---

## 💡 DICAS DE ILUMINAÇÃO

### Setup Básico (3 Pontos):

```
     KEY LIGHT (principal)
          ↓
    SUJEITO → CAMERA
     ↙    ↘
FILL    BACK
(luz    (luz
suave)  trás)
```

| Luz | Posição | Intensidade | Função |
|-----|---------|-------------|--------|
| **Key Light** | 45° frente | 100% | Luz principal |
| **Fill Light** | 45° oposto | 50% | Suavizar sombras |
| **Back Light** | Trás/topo | 75% | Separar do fundo |

### Setup Mínimo (1 Luz):

```
- Janela à frente (luz natural)
- Ring light à frente (se não houver janela)
- Telefone noutra mão como fill light
```

## ✂️ EDIÇÃO PARA RETENÇÃO

### Regra dos 3 Segundos:

```
A cada 3 segundos, algo deve MUDAR:
- Corte de ângulo
- Zoom in/out
- Texto no ecrã
- B-roll
- Transição
- Efeito sonoro
```

### Padrões de Corte:

**Para Reels (Rápido):**
```
0-3s: Hook visual + texto
3-10s: Cortes a cada 2-3s
10-30s: Cortes a cada 3-4s
30-60s: Cortes a cada 4-5s
```

**Para YouTube (Moderado):**
```
0-10s: Hook + intro
10-60s: Cortes a cada 5-8s
60-300s: Cortes a cada 8-12s
300s+: Cortes a cada 10-15s
```
