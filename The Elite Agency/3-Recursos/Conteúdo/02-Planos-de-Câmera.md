# 🎥 Planos de Câmera e Enquadramento

**Categoria:** #vídeo #produção #cinema
**Nível:** Fundamental

---

## 💡 Ideia Principal

> **O plano certo cria emoção, clareza e profissionalismo.** Escolhe o plano baseado no que queres transmitir, não no que é conveniente.

---

## 📐 TAMANHOS DE PLANO (DO MAIS FECHADO AO MAIS ABERTO)

---

### 1. EXTREME CLOSE-UP (ECU) — Detalhe

**Enquadramento:**
```
+-----------+
|     _     |
|    /|\    |
|     |     |
+-----------+
  Apenas olhos
  ou boca
```

**O que mostra:** Apenas os olhos, boca ou detalhe específico

**Quando usar:**
- Ênfase dramática extrema
- Mostrar emoção intensa (lágrimas, suor)
- Detalhes de produto (relógio, joia)
- Criar tensão/incomodo

**Exemplos:**
- Olhos a dilatar (medo/surpresa)
- Lábios a tremer (emoção)
- Gota de suor (tensão)

**Duração ideal:** 2-5 segundos

---

### 2. CLOSE-UP (CU) — Rosto

**Enquadramento:**
```
+-----------+
|  _______  |
| |       | |
| |  O O  | |
| |   ∆   | |
| |   _   | |
| |_______| |
+-----------+
  Rosto completo
  (testa ao queixo)
```

**O que mostra:** Rosto completo, ombros no máximo

**Quando usar:**
- Conversas emocionais
- Hooks de vídeos (conexão direta)
- Reações, emoções
- Confissões, verdades

**Duração ideal:** 5-15 segundos

**Dica:** Olhos nos 1/3 superiores do ecrã (regra dos terços)

---

### 3. MEDIUM CLOSE-UP (MCU) — Peito

**Enquadramento:**
```
+-----------+
|  _______  |
| |       | |
| |  O O  | |
| |   ∆   | |
| |   _   | |
| |_______| |
|    /|\    |
|     |     |
+-----------+
  Cabeça + peito
  (axilas para cima)
```

**O que mostra:** Cabeça e parte superior do torso

**Quando usar:**
- Talking head (YouTube, Reels)
- Entrevistas
- Apresentações
- Conteúdo educativo

**Duração ideal:** 10-60 segundos

**Vantagem:** Mostra expressões faciais + alguma linguagem corporal

---

### 4. MEDIUM SHOT (MS) — Cintura

**Enquadramento:**
```
+-----------+
|  _______  |
| |       | |
| |  O O  | |
| |   ∆   | |
| |   _   | |
| |_______| |
|    /|\    |
|  _ /|\ _  |
|   / | \   |
|    /|\    |
+-----------+
  Cabeça + torso
  (cintura para cima)
```

**O que mostra:** Da cintura para cima

**Quando usar:**
- Standard para YouTube
- Interações entre 2 pessoas
- Mostrar gestos das mãos
- Tutoriais com demonstração

**Duração ideal:** 15-90 segundos

**Vantagem:** Equilíbrio entre emoção facial e contexto corporal

---

### 5. MEDIUM WIDE SHOT (MWS) — Joelhos

**Enquadramento:**
```
+-----------+
|  _______  |
| |       | |
| |  O O  | |
| |   ∆   | |
| |   _   | |
| |_______| |
|    /|\    |
|  _/ | \_  |
|   / | \   |
|    /|\    |
|   / | \   |
|  _/   \_  |
+-----------+
  Cabeça + corpo
  (joelhos para cima)
```

**O que mostra:** Da maioria do corpo, joelhos para cima

**Quando usar:**
- Grupos de 2-3 pessoas
- Movimento limitado
- Mostrar outfit/look
- Antes/depois parcial

**Duração ideal:** 10-30 segundos

---

### 6. WIDE SHOT / FULL SHOT (WS/FS) — Corpo Inteiro

**Enquadramento:**
```
+-----------+
|  _______  |
| |       | |
| |  O O  | |
| |   ∆   | |
| |   _   | |
| |_______| |
|    /|\    |
|  _/ | \_  |
|   / | \   |
|    /|\    |
|   / | \   |
|  _/   \_  |
|   /   \   |
|  _     _  |
+-----------+
  Corpo inteiro
  (cabeça aos pés)
```

**O que mostra:** Corpo inteiro do sujeito

**Quando usar:**
- Mostrar outfit completo
- Danças, coreografias
- Before/after de corpo
- Estabelecer quem está na cena

**Duração ideal:** 5-20 segundos

---

### 7. EXTREME WIDE SHOT (EWS) — Paisagem

**Enquadramento:**
```
+-------------------+
|  ~~~~~~~~~~~~~~~  |
|   \           /   |
|    \    ●     /   |  ● = pessoa pequena
|     \       /     |
|  ~~~~~~~~~~~~~~~  |
+-------------------+
  Pessoa pequena
  no ambiente
```

**O que mostra:** Sujeito pequeno no ambiente/paisagem

**Quando usar:**
- Estabelecer localização
- Mostrar escala/grandeza
- Solidão/isolamento
- Transições entre cenas

**Duração ideal:** 3-10 segundos

## 🎬 ÂNGULOS DE CÂMERA

---

### 1. EYE LEVEL (Nível dos Olhos)

**Posição:**
```
CAMERA → 👁️ (mesmo nível)
```

**Efeito:** Neutro, igualdade, natural

**Quando usar:**
- Maioria dos vídeos
- Conversas normais
- Conteúdo educativo

---

### 2. HIGH ANGLE (De Cima)

**Posição:**
```
   CAMERA
      ↓
      👤
```

**Efeito:** Sujeito parece menor, fraco, vulnerável

**Quando usar:**
- Mostrar vulnerabilidade
- Crianças, animais
- Auto-depreciação (comédia)

**Exemplo:** "Eu antes de..." em transformações

---

### 3. LOW ANGLE (De Baixo)

**Posição:**
```
      👤
      ↑
   CAMERA
```

**Efeito:** Sujeito parece maior, poderoso, dominante

**Quando usar:**
- Mostrar autoridade/confiança
- "Eu depois de..." em transformações
- Villains em filmes

**Exemplo:** CEO a falar, atleta vencedor

---

### 4. DUTCH ANGLE (Inclinado)

**Posição:**
```
   CAMERA (inclinado 15-30°)
      ╱
     👤
```

**Efeito:** Tensão, desconforto, loucura

**Quando usar:**
- Criar tensão dramática
- Mostrar instabilidade emocional
- Comédia (exagero)

**Exemplo:** "Quando percebi que..."

---

### 5. OVERHEAD / TOP DOWN (De Cima 90°)

**Posição:**
```
   CAMERA
      ↓
   +-----+
   | MESA|
   |  📱 |
   +-----+
```

**Efeito:** Vista de Deus, organização, clareza

**Quando usar:**
- Unboxing
- Cooking videos
- Flat lay de produtos
- "Setup tours"

---

### 6. POV (Point of View)

**Posição:**
```
   CAMERA = OLHOS do sujeito
   O que a câmera vê = o que o sujeito vê
```

**Efeito:** Imersão, empatia, experiência

**Quando usar:**
- "Um dia comigo"
- Tutoriais de mãos
- Experiências imersivas
- "POV: tu és..."

---

## 🔄 MOVIMENTOS DE CÂMERA

---

### 1. PAN (Panorâmica)

**Movimento:** Câmera gira horizontalmente (esquerda → direita ou vice-versa)

**Visual:**
```
← ← ← CAMERA GIRA → → →
```

**Quando usar:**
- Seguir sujeito em movimento
- Revelar algo gradualmente
- Transição entre locais

---

### 2. TILT (Inclinação)

**Movimento:** Câmera gira verticalmente (cima → baixo ou vice-versa)

**Visual:**
```
↑ ↑ ↑
CAMERA
↓ ↓ ↓
```

**Quando usar:**
- Revelar sujeito de baixo para cima
- Mostrar altura de algo
- Transição criativa

---

### 3. DOLLY / TRACK (Deslocamento)

**Movimento:** Câmera move-se fisicamente para frente/trás/lado

**Visual:**
```
CAMERA → → → SUJEITO
```

**Quando usar:**
- Aproximar-se dramaticamente
- Seguir sujeito em movimento
- Criar dinamismo

---

### 4. ZOOM

**Movimento:** Lente aproxima/afasta (câmera não se move)

**Visual:**
```
🔍 [zoom in]  SUJEITO fica maior
🔍 [zoom out] SUJEITO fica menor
```

**Quando usar:**
- Zoom in: ênfase, revelação
- Zoom out: contexto, isolamento

**Dica:** Zoom rápido = dramático. Zoom lento = subtil.

---

### 5. PUSH IN / PULL OUT

**Movimento:** Câmera move-se fisicamente para mais perto/longe

**Visual:**
```
PUSH IN:  CAMERA → → → SUJEITO
PULL OUT: CAMERA ← ← ← SUJEITO
```

**Quando usar:**
- Push in: intensificar emoção, revelação
- Pull out: mostrar contexto, solidão, final de vídeo

---

### 6. ORBIT / ARC

**Movimento:** Câmera gira em redor do sujeito

**Visual:**
```
      CAMERA
     ↗     ↖
   ↗   SUJEITO   ↖
     ↘     ↙
      CAMERA
```

**Quando usar:**
- Mostrar produto 360°
- Hero shots (atleta, modelo)
- Momentos épicos

---

### 7. HANDHELD (Na Mão)

**Movimento:** Câmera treme ligeiramente (natural)

**Efeito:** Realismo, urgência, documental

**Quando usar:**
- Vlogs, behind the scenes
- Situações "reais"
- Criar energia/caos

**Dica:** Estabiliza na edição se necessário

## 📱 CONFIGURAÇÕES POR PLATAFORMA

---

### REELS / TIKTOK / SHORTS

| Configuração | Valor |
|--------------|-------|
| **Orientação** | Vertical (9:16) |
| **Resolução** | 1080x1920 |
| **FPS** | 30 ou 60 |
| **Duração Ideal** | 15-60s |
| **Hook** | 0-3s obrigatório |
| **Texto** | Grande, centro superior |
| **Zona Segura** | Evitar bordas (UI da app) |

**Zona Segura Reels:**
```
+---------------+
|  ~~~~~~~~~~~  | ← Evitar topo (nome, perfil)
|               |
|   CONTEÚDO    | ← Zona segura principal
|   PRINCIPAL   |
|               |
|  ~~~~~~~~~~~  | ← Evitar fundo (botões, legenda)
+---------------+
```

---

### YOUTUBE (Vídeos Longos)

| Configuração | Valor |
|--------------|-------|
| **Orientação** | Horizontal (16:9) |
| **Resolução** | 1920x1080 (mínimo), 3840x2160 (4K) |
| **FPS** | 24, 30 ou 60 |
| **Duração** | 8-20 min (sweet spot) |
| **Hook** | 0-15s |
| **Intro** | 0-30s máximo |

---

### YOUTUBE SHORTS

| Configuração | Valor |
|--------------|-------|
| **Orientação** | Vertical (9:16) |
| **Resolução** | 1080x1920 |
| **FPS** | 30 ou 60 |
| **Duração Máx** | 60s |
| **Hook** | 0-2s (ainda mais rápido!) |

## 🎯 GUIA RÁPIDO: QUE PLANO USAR?

| Situação | Plano Recomendado | Ângulo |
|----------|-------------------|--------|
| Hook emocional | Close-up | Eye level |
| Talking head | Medium close-up | Eye level |
| Tutorial mãos | Top down | 90° cima |
| Before/after corpo | Wide shot | Eye level |
| Mostrar autoridade | Medium shot | Low angle |
| Mostrar vulnerabilidade | Medium close-up | High angle |
| Unboxing | Top down + close-up | 90° cima |
| "Um dia comigo" | POV + medium | Variado |
| Produto 360° | Medium + orbit | Variado |
| Dança/coreografia | Full body | Eye level |
| Setup tour | Wide + pan | Eye level |
| Confissão/secredo | Extreme close-up | Eye level |

## 💡 Frases Para Lembrar

> "Plano errado = emoção errada."

> "Close-up = emoção. Wide = contexto."

> "Low angle = poder. High angle = vulnerabilidade."

> "Movimento cria dinamismo. Estático cria foco."

> "Zona segura do Reels ≠ YouTube. Ajusta o enquadramento."
