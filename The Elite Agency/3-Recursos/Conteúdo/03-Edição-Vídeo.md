## 💡 Ideia Principal

> **Edição não é cortar — é contar história.** Cada corte deve servir a narrativa, não só fazer parecer "fixe".

## ⚡ FLUXO DE EDIÇÃO RÁPIDA (15-30 MIN)

---

### Passo 1: Importar + Organizar (3 min)

```
1. Criar pasta do projeto
   ├── 01_Raw (vídeos brutos)
   ├── 02_Audio (músicas, SFX)
   ├── 03_Graphics (logos, textos)
   └── 04_Export (vídeos finais)

2. Importar tudo para o software
3. Selecionar melhores takes
```

---

### Passo 2: Corte Bruto (5 min)

```
1. Colocar melhor take na timeline
2. Cortar:
   - Inícios mortos (antes de falar)
   - Fins mortos (depois de falar)
   - Pausas longas (>2s)
   - Erros, "uhms", "ahms"

3. Juntar cortes (sem gaps)
```

**Dica:** Zoom in na timeline para cortes precisos

---

### Passo 3: Corte de Ritmo (5 min)

```
1. Assistir vídeo inteiro
2. Identificar partes lentas
3. Cortar ou acelerar:
   - Pausas de 1-2s → 0.5s
   - Frases repetidas → manter melhor
   - Partes chatas → cortar ou B-roll
```

**Regra:** Se não adiciona valor, CORTA.

---

### Passo 4: B-Roll + Visual (5 min)

```
1. Identificar pontos para B-roll:
   - Quando mencionas algo visual
   - Quando queres ilustrar ponto
   - Quando preciso de quebrar monotonia

2. Inserir B-roll por cima do A-roll
3. Ajustar duração (2-5s cada)
```

**Onde conseguir B-roll:**
- Pexels (grátis)
- Pixabay (grátis)
- Grava tu mesmo (melhor!)

---

### Passo 5: Texto + Legendas (5 min)

```
1. Adicionar hook text (0-3s)
2. Legendas automáticas (CapCut faz isto)
3. Destacar palavras chave (bold, cor)
4. Lower thirds (nome, cargo)
```

**Regra de Texto:**
- Máximo 7 palavras por linha
- 2 linhas máximo no ecrã
- Contrastar com fundo

---

### Passo 6: Áudio + Música (5 min)

```
1. Normalizar áudio (falar: -6 a -3 dB)
2. Adicionar música de fundo (-20 a -25 dB)
3. Adicionar SFX (transições, ênfases)
4. Fade in/out na música
```

**Níveis de Áudio:**
```
Fala:          -6 a -3 dB
Música fundo:  -20 a -25 dB
SFX:           -10 a -15 dB
Silêncio:      -∞ (corte total)
```

---

### Passo 7: Cor + Look (3 min)

```
1. Correção básica:
   - Exposição (nem muito claro/escuro)
   - Contraste (médio)
   - Saturação (ligeiro aumento)

2. Look/LUT (opcional):
   - Warm (laranja/teal)
   - Cool (azul)
   - B&W (dramático)
```

**Dica:** Menos é mais. Não exageres nos filtros.

---

### Passo 8: Exportar (2 min)

```
Configurações Reels/TikTok:
- Resolução: 1080x1920
- FPS: 30 ou 60
- Formato: MP4 (H.264)
- Bitrate: 15-20 Mbps

Configurações YouTube:
- Resolução: 1920x1080 ou 3840x2160 (4K)
- FPS: 24, 30 ou 60
- Formato: MP4 (H.264)
- Bitrate: 20-50 Mbps
```

## 🎞️ TÉCNICAS DE CORTE

---

### 1. J-CUT (Áudio Antes)

**O que é:** Áudio da próxima cena começa antes do vídeo

**Visual:**
```
Timeline:
Áudio A: ████████
Áudio B:         ████████
Vídeo A: ████████
Vídeo B:         ████████
           ↑
           Áudio B começa aqui (antes do vídeo B)
```

**Quando usar:**
- Transições suaves
- Criar antecipação
- Conversas (ouvimos antes de ver)

---

### 2. L-CUT (Áudio Depois)

**O que é:** Áudio da cena atual continua depois do vídeo cortar

**Visual:**
```
Timeline:
Áudio A: ████████
Áudio B:         ████████
Vídeo A: ████████
Vídeo B:         ████████
           ↑
           Áudio A continua aqui (depois do vídeo A)
```

**Quando usar:**
- Manter fluxo de conversa
- Voiceover contínuo
- Transições emocionais

---

### 3. CUT ON ACTION (Corte no Movimento)

**O que é:** Cortar durante movimento (não antes/depois)

**Exemplo:**
```
Cena A: Pessoa começa a levantar-se
Cena B: Pessoa já está a meio do movimento

Corta no meio da ação = transição invisível
```

**Quando usar:**
- Qualquer movimento físico
- Virar de cabeça
- Gestos com mãos
- Caminhar

---

### 4. MATCH CUT (Corte por Similaridade)

**O que é:** Cortar entre cenas com composição similar

**Exemplo:**
```
Cena A: 🌕 (lua cheia)
Cena B: 🍊 (laranja em close-up)

Ambos são círculos = corte suave
```

**Quando usar:**
- Transições criativas
- Mudar de localização
- Passagem de tempo

---

### 5. JUMP CUT (Corte de Salto)

**O que é:** Cortar no mesmo enquadramento, tempo salta

**Visual:**
```
0:00 - 0:05: "Hoje vou mostrar-vos..."
0:05 - 0:10: [CORTE] "...como fazer isto"
0:10 - 0:15: [CORTE] "Primeiro passo..."
```

**Quando usar:**
- Vídeos educativos
- Passagem de tempo rápida
- Criar energia/ritmo

**Dica:** Manter mesmo enquadramento para funcionar

## 📊 RETENÇÃO DE AUDIÊNCIA

---

### Como Analisar Retenção

**YouTube Studio:**
```
YouTube Analytics → Retenção de Audiência

Gráfico mostra % de espectadores em cada segundo

0:00 → 100% (todos começam)
0:30 → 70%? 50%? 30%? (depende do vídeo)
Fim → 20-40% (bom para vídeos longos)
```

**Reels/TikTok:**
```
Analytics → Retenção

Métricas chave:
- Tempo médio de visualização
- % que viu até ao fim
- Re-watch rate (quantos viram 2x+)
```

---

### Pontos de Queda Comuns

| Segundo | Por Que as Pessoas Saem | Como Fixar |
|---------|------------------------|------------|
| 0-3s | Hook fraco | Hook visual + texto forte |
| 10-15s | Promessa não entregue | Entregar valor mais cedo |
| 30-45s | Ritmo lento | Cortar mais, B-roll |
| 60s+ | Perderam interesse | CTA mais cedo, dividir em partes |

---

### Como Melhorar Retenção

**Antes dos 3s:**
- [ ] Hook visual (movimento, expressão)
- [ ] Hook de texto (título no ecrã)
- [ ] Hook de áudio (frase impactante)

**Entre 3-15s:**
- [ ] Entregar promessa do hook
- [ ] Estabelecer credibilidade
- [ ] Criar curiosidade

**Entre 15-60s:**
- [ ] Manter ritmo (cortes a cada 3-5s)
- [ ] B-roll relevante
- [ ] Texto/legendas dinâmicas

**Após 60s:**
- [ ] Dividir em partes (Parte 1, 2, 3)
- [ ] CTA no meio ("Segue para parte 2")
- [ ] Cliffhanger antes do fim

## 🎬 TRANSIÇÕES

---

### Transições Básicas

| Transição | Duração | Quando Usar |
|-----------|---------|-------------|
| **Cut (Corte)** | 0s | 90% das vezes (invisível) |
| **Fade In/Out** | 0.5-1s | Início/fim de vídeo |
| **Dissolve** | 0.5-1s | Passagem de tempo suave |
| **Wipe** | 0.3-0.5s | Mudar de tópico |

**Regra:** Usa corte simples 90% do tempo. Transições "fixes" distraem.

---

### Transições Virais (TikTok/Reels)

| Transição | Como Fazer | Quando Usar |
|-----------|------------|-------------|
| **Snap Transition** | Estalar dedos, cortar no snap | Mudar outfit, local |
| **Hand Cover** | Mão cobre lente, corta, revela | Transição mágica |
| **Spin Transition** | Girar câmera, cortar no movimento | Mudar cenário |
| **Object Throw** | Atirar objeto, cortar, apanhar | Criativo, divertido |
| **Zoom Transition** | Zoom in rápido, cortar, zoom out | Ênfase, mudança |

## 📱 TEMPLATE DE EXPORTAÇÃO

---

### Reels / TikTok / Shorts

```
Formato: MP4 (H.264)
Resolução: 1080 x 1920 (9:16)
FPS: 30 ou 60
Bitrate: 15-20 Mbps
Áudio: AAC, 48kHz, -6 a -3 dB
Duração Máx: 60s (Reels), 60s (Shorts), 180s (TikTok)
Tamanho Máx: 100MB (Reels), 256MB (YouTube)
```

```
Formato: MP4 (H.264)
Resolução: 1920 x 1080 ou 3840 x 2160 (4K)
FPS: 24 (cinema), 30 (standard), 60 (smooth)
Bitrate: 20-50 Mbps (1080p), 50-100 Mbps (4K)
Áudio: AAC, 48kHz, -6 a -3 dB
Duração: Até 12 horas
Tamanho Máx: 256GB
```
