# Princípios de Negociação

**Categoria:** #negociação #vendas #fechamento
**Nível:** Intermediário

---

## 💡 Ideia Principal

> **Negociação não é vencer o cliente — é chegar a um acordo onde ambos ganham.** Se um perde, o deal morre depois.

---

## 🏛️ OS 7 PRINCÍPIOS FUNDAMENTAIS

---

### 1. QUEM PRECISA MENOS, TEM MAIS PODER 💪

**Princípio:**
> O lado que precisa menos do deal tem mais poder na negociação.

**Como aplicar:**
- Nunca negocies como se *precisasses* do cliente
- Mostra que trabalhas com outros clientes (mesmo que não tenhas)
- Está disposto a dizer "não" e ir embora

**Exemplo:**
```
Errado: "Por favor, preciso mesmo deste cliente..."
Certo: "Se não for fit, não há problema. Segui-mos."
```

**Frase para usar:**
> "Trabalho com quem tem fit. Se não for o vosso caso,
> não há problema."

---

### 2. NUNCA CEDAS SEM RECEBERES 🔄

**Princípio:**
> Cada concessão tua deve ser trocada por uma concessão deles.

**Como aplicar:**
- Nunca dês desconto "grátis"
- Troca preço por condições (pagamento upfront, contrato mais longo, etc.)

**Exemplo:**
```
Cliente: "Fazem desconto?"

Errado: "Posso fazer 10%..."
Certo: "Posso fazer 10% se fecharmos hoje e pagamento
       upfront trimestral. Faz sentido?"
```

**Fórmula:**
> SE [concessão tua] → ENTÃO [concessão deles]

---

### 3. O PRIMEIRO A FALAR NÚMEROS, PERDE 🔢

**Princípio:**
> Quem diz o primeiro número ancora a negociação naquele valor.

**Como aplicar:**
- Se perguntarem preço, não digas imediatamente
- Pergunta qual é o orçamento deles primeiro
- Se deres preço, ancora com valor alto primeiro

**Exemplo:**
```
Cliente: "Quanto custa?"

Tu: "Depende do escopo. Qual é o orçamento que têm
     alocado para isto?"

[Se ele disser €1.000/mês]

Tu: "Perfeito. Dentro desse orçamento, podemos fazer X, Y, Z."
```

**Se não deres preço primeiro:**
> "Normalmente os nossos pacotes começam em €500-€1.500/mês,
> dependendo do escopo. Qual faz mais sentido para ti?"

---

### 4. SILENCIO É OURO 🤫

**Princípio:**
> Depois de dizeres preço ou fazeres uma oferta: CALA-TE.

**Como aplicar:**
- Diz o preço
- Conta até 10 mentalmente (ou mais)
- Não preenchas o silêncio

**O que acontece:**
- O cliente sente pressão
- Ele vai preencher o silêncio
- Geralmente com uma concessão ou "sim"

**Exemplo:**
```
Tu: "O investimento é €600/mês."
[Silêncio - 10 segundos]
Cliente: "Bem... acho que podemos tentar."
```

---

### 5. JUSTIFICA CADA NÚMERO 📊

**Princípio:**
> Um número sem justificação parece arbitrário. Um número justificado parece lógico.

**Como aplicar:**
- Nunca digas apenas o preço
- Mostra a matemática por trás
- Compara com o custo do problema

**Exemplo:**
```
Errado: "É €600/mês."

Certo: "Deixa-me mostrar a matemática:
        - Disseste que cada carro parado custa €500/mês
        - Tens 20 carros parados = €10.000/mês perdidos
        - O meu serviço é €600/mês = 6% do problema
        - Basta resolver 1 carro para pagar 8 meses
        
        Quem está a ser caro aqui?"
```

---

### 6. CRIA COMPETIÇÃO 🏆

**Princípio:**
> Pessoas querem o que outros também querem.

**Como aplicar:**
- Mostra que tens outros clientes/leads
- Cria escassez real (não falsa)
- Usa prova social

**Exemplo:**
```
"Só tenho 2 vagas este mês porque estou com 3 onboardings
a acontecer. Querias garantir uma antes de fechar?"

"Trabalho com 10 empresas similares à vossa.
A vossa concorrência [Empresa X] já está a ter resultados."
```

**Cuidado:** Não mintas. Escassez falsa destrói confiança.

---

### 7. TERMINA SEMPRE COM PRÓXIMOS PASSOS 📍

**Princípio:**
> Uma negociação sem próximos passos definidos está morta.

**Como aplicar:**
- Nunca termines uma call sem ação concreta
- Define data, hora e responsável
- Envia confirmação por escrito

**Exemplo:**
```
"Perfeito. Então fica assim:

- Eu envio a proposta até amanhã às 10h
- Tu revês com o sócio até quarta
- Quarta às 15h fazemos call de 15 min para dúvidas
- Quinta assinamos e começamos

Faz sentido? Envio-te o invite da call de quarta?"
```

## 🎯 PODER NA NEGOCIAÇÃO

### Fontes de Poder:

| Fonte | Como Criar | Exemplo |
|-------|------------|---------|
| **Informação** | Saber mais que o outro | Conhecer o LTV do cliente |
| **Alternativas** | Ter outras opções | Outros clientes no pipeline |
| **Urgência** | Controlar o timing | "Só tenho 2 vagas este mês" |
| **Autoridade** | Ser percebido como expert | Cases, resultados, prova social |
| **Risco** | Quem arrisca menos tem poder | Contrato mês a mês, não anual |

---

## 🔄 A DANÇA DA NEGOCIAÇÃO

```
1. ABERTURA → Criar rapport, estabelecer confiança
2. EXPLORAÇÃO → Descobrir necessidades, orçamento, timing
3. PROPOSTA → Apresentar solução com valor justificado
4. OBJEÇÕES → Lidar com preocupações (usa LAER)
5. CONCESSÕES → Trocar concessões, nunca ceder grátis
6. FECHO → Definir próximos passos concretos
```

**Erro comum:** Pular direto para 3 (Proposta) sem fazer 2 (Exploração).

---

## ⚠️ ERROS QUE DESTRUÓI NEGOCIAÇÕES

| Erro | Impacto | Como Evitar |
|------|---------|-------------|
| Falar de preço cedo | Ancoragem baixa | Adia, pergunta orçamento |
| Ceder sem receber | Perde valor, não fecha | Sempre troca |
| Não ouvir objeções | Não resolve preocupações | Usa LAER |
| Ficar na defensiva | Parece fraco | Mantém calma, confiança |
| Criar urgência falsa | Perde confiança | Só usa urgência real |
| Não definir próximos passos | Deal morre | Sempre agenda algo |
| Aceitar primeiro "não" | Perde deals salváveis | Explora mais fundo |

## 🎭 TÁTICAS DE NEGOCIAÇÃO (PARA USAR E DEFENDER)

### Tática: "É o meu último preço"

**O que é:** Cliente diz que não pode pagar mais.

**Como responder:**
```
"Entendo perfeitamente. Se orçamento é limitação real,
podemos reduzir escopo.

Em vez de X+Y+Z, fazemos apenas X+Y por €[menor].

Faz sentido?"
```

---

### Tática: "O teu concorrente faz mais barato"

**O que é:** Cliente usa concorrência para baixar preço.

**Como responder:**
```
"Entendo. E o que ele inclui nesse preço?

[Ouve]

A diferença é [X, Y, Z]. Normalmente quando vejo
preço muito baixo, é porque [não inclui isto/aquilo].

Queres comparar features lado a lado?"
```

---

### Tática: "Preciso de 50% de desconto"

**O que é:** Pedido agressivo de desconto.

**Como responder:**
```
"Consigo fazer 50% de desconto se:
- Reduzirmos 50% do escopo
- Ou fechares contrato de 24 meses upfront

Qual faz mais sentido para ti?"
```

---

### Tática: "Vou pensar"

**O que é:** Adiamento (pode ser objeção disfarçada).

**Como responder:**
```
"Claro, é uma decisão importante.

O que exatamente precisas de pensar?
É sobre [timing/orçamento/resultado/equipa]?

[Se não disser]

Posso perguntar diretamente: há uma preocupação
específica que te faz hesitar?"
```

---

## 📊 CHECKLIST PRÉ-NEGOCIAÇÃO

Antes de entrar numa negociação:

- [ ] Sei quem é o decisor?
- [ ] Conheço o orçamento deles (ou range)?
- [ ] Sei qual é o problema real (em euros)?
- [ ] Tenho cases similares para mostrar?
- [ ] Sei qual é o timing/urgência deles?
- [ ] Tenho alternativa se este deal não fechar?
- [ ] Sei quais são os próximos passos se fechar?
