# 🚦 Sinais de Compra

**Categoria:** #fechamento #timing #vendas
**Nível:** Intermediário

---

## 💡 Ideia Principal

> O timing do fechamento é mais importante que a técnica de fechamento.

---

## 📖 Sinais Verbais de Que o Cliente Está Pronto

### 🟢 Sinais Fortes (Hora de Fechar)

| Sinal | O Que Significa |
|-------|-----------------|
| "Quando começa?" | Já decidiu mentalmente |
| "Como funciona a implementação?" | Visualizando uso |
| "Quanto tempo leva?" | Planejando logistics |
| "Tem garantia?" | Reduzindo risco mental |
| "Posso falar com X?" | Buscando validação final |
| "Fazemos assim..." | Negociando termos |

### 🟡 Sinais Moderados (Aquecer para Fechamento)

| Sinal | Ação Recomendada |
|-------|------------------|
| "Interessante..." | Aprofundar benefícios |
| "Já usei algo similar" | Pedir comparação |
| "Quanto custa?" | Falar de valor antes |
| "Vou pensar" | Identificar objeção real |
| "Preciso falar com X" | Envolver decisor |

### 🔴 Sinais de Alerta (Não Fechar Ainda)

| Sinal | Problema Provável |
|-------|-------------------|
| Silêncio prolongado | Não entendeu valor |
| "Me manda informação" | Não está convencido |
| "Vamos ver depois" | Sem urgência/necessidade |
| "Preço está alto" | Não viu ROI suficiente |
| "Preciso de mais tempo" | Medo ou desconfiança |

---

## 📊 Sinais Não-Verbais

### Positivos ✅
- Inclina para frente
- Concorda com a cabeça
- Sorri genuinamente
- Relaxa a postura
- Faz anotações
- Olha nos olhos

### Negativos ❌
- Cruza braços
- Olha para o relógio/celular
- Postura fechada
- Expressão preocupada
- Distraído

## 🎯 Teste de Temperatura

Antes de fechar, **teste** se o cliente está pronto:

### Teste 1: Pergunta de Confirmação
> "Isso faz sentido para você?"

Se a resposta for "sim" genuíno → Continue
Se for "acho que sim" → Volte para benefícios

### Teste 2: Pergunta de Implementação
> "Como você imagina isso funcionando na sua rotina?"

Se descrever uso → Está visualizando (bom sinal)
Se não conseguir imaginar → Não entendeu valor

### Teste 3: Pergunta de Compromisso
> "Se resolvermos [X], você está pronto para avançar?"

Se sim → Vá para o fechamento
Se não → Há objeção não dita

## ❓ Perguntas de Revisão

1. **Qual o erro mais comum no timing?**
   - Fechar cedo demais (antes do cliente estar convencido)

2. **O que fazer se fechar e o cliente disser "não"?**
   - Não insista. Pergunte: "O que te faz dizer não?" e volte uma etapa.

3. **Como praticar leitura de sinais?**
   - Grave suas reuniões (com permissão)
   - Revise e identifique sinais que perdeu
   - Peça feedback de colegas experientes

## 📝 Regra de Ouro

> **Se você precisa se perguntar "será que é hora de fechar?"**

Quando é a hora certa, você **sabe**. O cliente praticamente se fecha sozinho.
