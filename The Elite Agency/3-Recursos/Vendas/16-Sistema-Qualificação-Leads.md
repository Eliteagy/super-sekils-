# Sistema de Qualificação de Leads

**Categoria:** #qualificação #vendas #icp
**Nível:** Intermediário
**Fonte:** Mentoria 2026-03-29

---

## 💡 Ideia Principal

> **Nem toda a lead merece uma reunião.** Qualifica ANTES para evitar no-shows, perda de tempo e clientes que não fecham.

---

## 📊 FRAMEWORK DE QUALIFICAÇÃO

### Nível 1: Qualificação Automática (Antes da Call)

**Critérios Eliminatórios:**

| Critério | Passa ❌ | Não Passa ✅ |
|----------|----------|--------------|
| LTV do cliente | > €15.000 | < €5.000 |
| Faturação mensal | > €20.000/mês | < €5.000/mês |
| Ticket médio | > €1.000 | < €500 |
| Margem | > 30% | < 15% |
| Decisor na call | Sim | Não |
| Urgência | Alta (problema atual) | Baixa (só explorar) |

**Regra:** Se falhar 2+ critérios → **Não agendar reunião**

---

### Nível 2: Score de Prioridade (1-10)

**Calcula o score somando:**

| Fator | Pontos |
|-------|--------|
| LTV > €50.000 | +3 |
| LTV €20.000-€50.000 | +2 |
| LTV €10.000-€20.000 | +1 |
| Faturação > €50.000/mês | +2 |
| Faturação €20.000-€50.000/mês | +1 |
| Ticket médio > €5.000 | +2 |
| Ticket médio €1.000-€5.000 | +1 |
| Decisor direto | +2 |
| Urgência alta (problema agora) | +2 |
| Já investiu em marketing antes | +1 |
| Referenciado por cliente | +2 |

**Interpretação:**
- **8-10 pontos:** Prioridade máxima → Agendar já
- **5-7 pontos:** Qualifica com ressalvas → Agendar se tiveres capacidade
- **< 5 pontos:** Não qualifica → Não agendar

## 🎯 CALL DE QUALIFICAÇÃO (10 min)

### Se o formulário for positivo, faz uma mini-call de 10 min:

**Script:**

```
"Olá [Nome], obrigado por preencheres o formulário.

Vou ser direto: esta call é para eu entender se conseguimos
ajudar-te mesmo. Se não formos fit, digo-te na mesma e talvez
consiga recomendar outra solução.

Dito isto, deixa-me fazer 3 perguntas rápidas:"

1. "O que te levou a preencher o formulário hoje?"
   → Procurar: urgência, dor real

2. "Se não resolveres isto nos próximos 3 meses, qual é o impacto?"
   → Procurar: consequência real de não agir

3. "Qual é o processo de decisão na vossa empresa?
   Quem mais precisa de aprovar?"
   → Procurar: se é decisor ou não

"Perfeito. Com base no que me disseste, [parece que somos fit /
não somos o fit ideal].

Se formos em frente, o próximo passo é uma call de 30 minutos
para eu entender o negócio a fundo e apresentar como trabalhamos.

Faz sentido agendarmos?"
```

## ✅ CHECKLIST DE QUALIFICAÇÃO

### Antes de Agendar:

- [ ] LTV > €10.000 (mínimo)
- [ ] Faturação > €10.000/mês
- [ ] Ticket médio > €500
- [ ] Preencheu formulário completo
- [ ] Respondeu a todas as perguntas
- [ ] Decisor ou tem acesso ao decisor
- [ ] Urgência real (não só "explorar")
- [ ] Orçamento alinhado (€500+)

**Se todos ✅ → Agendar reunião**
**Se 1-2 ❌ → Qualificar com cuidado**
**Se 3+ ❌ → Não agendar**

## 🚩 RED FLAGS (Não Aceitar)

| Red Flag | Por Que Evitar | Exemplo |
|----------|----------------|---------|
| Não sabe números | Não valoriza dados, não trackea | "Não faço ideia" |
| Faturação < €5.000/mês | Não consegue pagar | "Fazemos €3.000/mês" |
| Ticket < €500 | LTV baixo, não justifica | "Vendemos a €200" |
| Não é decisor | Vais perder tempo | "Preciso falar com meu sócio" |
| Sem urgência | Nunca vai avançar | "Só estou a explorar" |
| Já teve 5+ agências | Provavelmente o problema é ele | "Já tentei tudo" |
| Culpa todos os outros | Não assume responsabilidade | "Todas as agências são incompetentes" |
| Expectativas irreais | Vai ficar desiludido | "Quero 10x em 1 mês" |
| Negócio ilegal/limite | Risco para ti | "Não posso mostrar a cara" |
| Pede desconto logo | Não valoriza, só quer preço | "Fazem desconto?" |

## 🟡 AMARELO (Qualificar com Cuidado)

| Sinal | O Que Investigar | Pergunta para Fazer |
|-------|------------------|---------------------|
| Faturação €5.000-€10.000 | Tem capacidade de crescer? | "Qual é o vosso objetivo de faturação?" |
| Ticket €300-€500 | Tem volume suficiente? | "Quantas vendas fazes por mês?" |
| "Preciso falar com sócio" | É influente ou só mensageiro? | "Qual o papel dele na decisão?" |
| Já teve 2-3 agências | O que correu mal? | "O que falhou nas parcerias anteriores?" |
| Sem urgência clara | Tem dor real? | "O que muda se não fizeres nada?" |

## 📊 SCRIPT DE REJEIÇÃO (Quando Não É Fit)

### Quando a lead não qualifica:

```
[Nome],

Obrigado pelo tempo e transparência.

Após analisarmos o teu caso, acredito que não somos
a agência certa para ti neste momento.

O que observámos:
- [Razão 1: ex: faturação atual não suporta o investimento]
- [Razão 2: ex: urgência não é suficiente]
- [Razão 3: ex: já tens solução interna]

Isto não é negativo — apenas significa que o timing
ou o fit não estão certos.

Recomendo que [alternativa: ex: invistas em X primeiro,
procures uma agência mais júnior, etc.].

Se no futuro a situação mudar, estou por aqui.

Todo o sucesso!

[Teu nome]
```

---

### Quando a lead é "amarela":

```
[Nome],

Com base no que partilhaste, somos cautious otimistas.

O que nos faz pensar que pode funcionar:
- [Ponto positivo 1]
- [Ponto positivo 2]

O que nos preocupa:
- [Preocupação 1]
- [Preocupação 2]

Se estiveres disposto/a a trabalhar nestes pontos,
podemos avançar. Caso contrário, talvez não seja o fit.

O que achas?

[Teu nome]
```

