# Pipeline de Vendas

**Categoria:** #gestão #vendas #métricas
**Nível:** Intermediário

---

## 💡 Ideia Principal

> O pipeline é o **mapa visual** de todas as suas oportunidades — saber gerenciá-lo é a diferença entre bater metas ou não.

---

## 📖 O Que É um Pipeline?

```
                    FUNIL DE VENDAS

    ┌─────────────────────────────────┐
    │     TOPO: Leads / Prospects     │  ← 100 contatos
    │            (100%)               │
    ├─────────────────────────────────┤
    │   MEIO: Qualificados / Reunião  │  ← 40 oportunidades
    │            (40%)                │
    ├─────────────────────────────────┤
    │  FUNDO: Proposta / Negociação   │  ← 15 negociações
    │            (15%)                │
    ├─────────────────────────────────┤
    │     BASE: Fechados / Won        │  ← 8 vendas (8%)
    │            (8%)                 │
    └─────────────────────────────────┘
```

---

## 📊 Etapas Típicas do Pipeline

| Etapa | Critério de Entrada | % Conversão | Tempo Médio |
|-------|---------------------|-------------|-------------|
| Lead | Primeiro contato | 100% | - |
| Prospect Qualificado | BANT confirmado | 40-50% | 2-5 dias |
| Reunião de Descoberta | Agenda confirmada | 25-35% | 5-10 dias |
| Proposta Enviada | Documento enviado | 15-20% | 10-20 dias |
| Negociação | Counter-offer | 10-15% | 15-30 dias |
| Fechado | Contrato assinado | 5-10% | 30-60 dias |

---

## 🎯 Métricas Essenciais

### 1. Taxa de Conversão por Etapa
```
Conversão = (Oportunidades que avançam) / (Total na etapa) × 100
```

### 2. Velocidade do Pipeline
```
Velocidade = (Oportunidades × Ticket Médio × Taxa) / Ciclo de Vendas
```

### 3. Coverage Ratio
```
Coverage = Pipeline Total / Meta do Período
```
**Regra:** Mínimo 3x para SaaS, 5x para enterprise

---

## ⚠️ Problemas Comuns

| Sintoma              | Causa Provável     | Solução                |
| -------------------- | ------------------ | ---------------------- |
| Pipeline vazio       | Pouca prospecção   | Bloquear 2h/dia        |
| Muitas oportunidades | Qualificação fraca | Critérios mais rígidos |
| Estagnado            | Sem follow-up      | Cadência definida      |
| Conversão baixa      | Pitch errado       | Melhorar descoberta    |
| Ciclo longo          | Sem urgência       | Criar gatilhos         |

---

## 🔧 Como Otimizar

### Semanalmente:
- [ ] Revisar todas as oportunidades
- [ ] Remover "zumbis" (sem progresso 30+ dias)
- [ ] Identificar riscos de churn
- [ ] Planejar ações de aceleração

### Mensalmente:
- [ ] Analisar conversão por etapa
- [ ] Calcular velocidade média
- [ ] Ajustar previsões
- [ ] Rebalancear esforços
