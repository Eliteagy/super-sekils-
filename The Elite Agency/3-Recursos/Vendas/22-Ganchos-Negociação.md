# Ganchos de Negociação

**Categoria:** #negociação #vendas #scripts #fechamento
**Nível:** Intermediário

---

## 💡 Ideia Principal

> **Ganchos são frases preparadas que te dão controlo na negociação.** Usas no momento certo para desarmar objeções, criar valor, ou fechar.

---

## 🎣 OS 25 GANCHOS DE NEGOCIAÇÃO

---

### GANCHOS DE ABERTURA

---

#### 1. "Antes de Começarmos..." 🎯

**Quando usar:** No início da call, para estabeleceres controlo.

**Script:**
```
"Antes de começarmos, quero confirmar uma coisa:

Temos 30 minutos agendados. O meu objetivo é entender
o teu negócio e ver se faz sentido trabalharmos juntos.

Se no final fizer sentido, ótimo. Se não fizer,
também está tudo bem — pelo menos ficas com um insight
ou dois que podes aplicar.

Faz sentido para ti?"
```

**Por que funciona:**
- Define expectativas claras
- Tira pressão do cliente
- Cria ambiente de "sem compromisso"

---

#### 2. "Qual É o Teu Objetivo Hoje?" 📍

**Quando usar:** Logo após o início, para entenderes a intenção.

**Script:**
```
"Perfeito. Antes de te fazer perguntas, quero entender:

Qual é o teu objetivo com esta call?

O que precisas de sair disto para sentires que valeu a pena?"
```

**Por que funciona:**
- O cliente revela o que realmente quer
- Dá-te informação para o fecho depois
- Mostra que te importas com o resultado dele

---

#### 3. "Isto É Para Ti?" 🎯

**Quando usar:** Para qualificar rapidamente.

**Script:**
```
"Sendo honesto: não trabalho com toda a gente.

Trabalho apenas com [teu ICP: ex: empresas de X,
com faturação Y, que querem Z].

Pelo que me disseste, parecem ser fit.

Tu sentes o mesmo?"
```

**Por que funciona:**
- Inverte o jogo (tu escolhes, não és escolhido)
- Cria escassez
- Faz o cliente "querer ser escolhido"

---

### GANCHOS DE DESCOBERTA

---

#### 4. "E Além Disso?" 🔍

**Quando usar:** Depois do cliente dar uma resposta.

**Script:**
```
"Entendi. E além disso, o que mais?

O que mais está a afectar o teu negócio?"
```

**Por que funciona:**
- Revela problemas adicionais
- Mostra que queres entender a fundo
- Cria mais "dor" para justificar valor depois

---

#### 5. "Como É Que Isso Te Afecta?" 💔

**Quando usar:** Quando o cliente menciona um problema.

**Script:**
```
"Ok, então [repete o problema].

Como é que isso te afecta pessoalmente?

Qual é o impacto no teu dia-a-dia?"
```

**Por que funciona:**
- Torna o problema pessoal/emocional
- Conecta problema a consequências reais
- Cria urgência interna

---

#### 6. "O Que Já Tentaste?" 🔄

**Quando usar:** Para entender histórico e frustrações.

**Script:**
```
"Antes de avançarmos: o que já tentaste para resolver isto?

O que funcionou? O que não funcionou?

Por que achas que não funcionou?"
```

**Por que funciona:**
- Mostra que não vais oferecer a mesma solução falhada
- Revela objecções antecipadas ("já tentei isso")
- Dá-te informação para posicionares tua solução

---

#### 7. "E Se Não Fizeres Nada?" ⏰

**Quando usar:** Para criar urgência real.

**Script:**
```
"Deixa eu te fazer uma pergunta direta:

Se não resolveres isto nos próximos 6 meses,
o que acontece?

Onde está o teu negócio? E tu pessoalmente?"
```

**Por que funciona:**
- Força o cliente a confrontar consequências
- Cria urgência sem ser agressivo
- Mostra que "não decidir" é uma decisão (cara)

---

#### 8. "Qual É o Custo Real?" 💰

**Quando usar:** Para quantificar o problema em euros.

**Script:**
```
"Disseste que [problema] acontece [X vezes por semana].

Vamos fazer matemática rápida:

- Cada vez custa €[X]
- Por mês: €[X] × [4 semanas] = €[Y]
- Por ano: €[Y] × 12 = €[Z]

É isto? Estou a esquecer alguma coisa?"
```

**Por que funciona:**
- Transforma problema abstrato em número concreto
- Justifica teu preço depois
- Cliente vê o custo de não agir

---

### GANCHOS DE PREÇO

---

#### 9. "Qual É o Teu Orçamento?" 💵

**Quando usar:** Antes de dizeres preço.

**Script:**
```
"O investimento depende do escopo.

Para eu não sugerir coisas fora do que têm alocado:
qual é o orçamento que têm para este projeto?"
```

**Por que funciona:**
- Evitas ancorar baixo
- Se o orçamento for alto, não deixas dinheiro na mesa
- Se for baixo, sabes logo e podes qualificar para fora

---

#### 10. "Se O Preço Não Fosse Problema..." 🎯

**Quando usar:** Quando o cliente foca só no preço.

**Script:**
```
"Entendo que orçamento é uma consideração importante.

Mas deixa eu te perguntar:

Se o preço não fosse um problema,
esta seria a solução ideal para ti?"
```

**Por que funciona:**
- Separa objeção de preço de objeção real
- Se disser "sim": trabalhas apenas o valor
- Se disser "não": há outra objeção oculta

---

#### 11. "Caro Comparado Com Quê?" ⚖️

**Quando usar:** Quando cliente diz "é caro".

**Script:**
```
"Entendo. Posso perguntar:

Caro comparado com quê?

Comparado com o problema que tens?
Comparado com alternativas?
Comparado com não fazer nada?"
```

**Por que funciona:**
- Muda o frame de comparação
- Força cliente a definir referência
- Abre espaço para justificares valor

---

#### 12. "O Que Seria Justo?" 🤝

**Quando usar:** Quando cliente pede desconto agressivo.

**Script:**
```
"Entendo que queres o melhor deal possível.

Para eu entender: o que seria um investimento justo
para ti, considerando o valor que vais receber?"
```

**Por que funciona:**
- Traz cliente para realidade
- Pode revelar que ele aceita preço próximo do teu
- Mostra que estás aberto, mas não desesperado

---

#### 13. "Posso Fazer X Por Y" 🔄

**Quando usar:** Para trocar concessões.

**Script:**
```
"Consigo fazer [desconto/condição] se:

- Fecharmos hoje
- E [pagamento upfront/contrato mais longo]

Faz sentido para ti?"
```

**Por que funciona:**
- Nunca cedes sem receberes
- Cria urgência real
- Justifica desconto com compromisso

---

### GANCHOS DE OBJEÇÃO

---

#### 14. "O Que Mais?" 📋

**Quando usar:** Quando cliente dá primeira objeção.

**Script:**
```
"Entendo. O que mais?

Há mais alguma preocupação que queiras partilhar?"
```

**Por que funciona:**
- Revela todas as objeções de uma vez
- Primeira objeção pode não ser a real
- Podes resolver tudo de uma vez

---

#### 15. "Só Uma Coisa?" 🔍

**Quando usar:** Quando cliente diz "só preciso de pensar".

**Script:**
```
"Claro, é uma decisão importante.

Só uma coisa: normalmente quando alguém diz isto,
é porque há uma preocupação específica.

Posso perguntar diretamente: o que te faz hesitar?"
```

**Por que funciona:**
- Vai direto à objeção real
- Mostra que entendes o jogo
- Cria espaço para honestidade

---

#### 16. "Se Eu Resolvesse Isso...?" ✅

**Quando usar:** Para testar se objeção é real.

**Script:**
```
"Entendi a tua preocupação com [objeção].

Se eu conseguisse resolver isso completamente,
haveria mais alguma razão para não avançarmos?"
```

**Por que funciona:**
- Confirma se é objeção real ou desculpa
- Se disser "não": estás perto do fecho
- Se disser "sim": revela objeção verdadeira

---

#### 17. "Já Trabalhou Com Alguém Como Eu?" 🏢

**Quando usar:** Quando cliente mostra desconfiança.

**Script:**
```
"Posso perguntar: já trabalhaste com [agências/freelancers/
pessoas como eu] antes?

O que correu bem? O que correu mal?"
```

**Por que funciona:**
- Revela traumas passados
- Podes abordar medos diretamente
- Mostra empatia

---

### GANCHOS DE FECHO

---

#### 18. "Faz Sentido?" ✔️

**Quando usar:** Após apresentar valor ou solução.

**Script:**
```
[Impactar valor]

"Faz sentido para ti?"
```

**Por que funciona:**
- Pequeno "sim" leva a "sim" maior
- Cria momentum de concordância
- Se disser "não": sabes que há objeção

---

#### 19. "Qual Faz Mais Sentido?" 🅰️🅱️

**Quando usar:** Para dar escolha que não é "sim ou não".

**Script:**
```
"Temos duas opções:

Opção A: [pacote básico] — €X
Opção B: [pacote completo] — €Y

Qual faz mais sentido para o teu momento?"
```

**Por que funciona:**
- Escolha é entre duas opções tuas
- Não é entre "sim e não"
- Cliente sente que controla

---

#### 20. "Quando Queres Começar?" 📅

**Quando usar:** Quando sentes que cliente está convencido.

**Script:**
```
[Pós-apresentação de valor]

"Se fizer sentido, quando queres começar?

Temos vagas para [Dia X] ou [Dia Y].
Qual funciona melhor?"
```

**Por que funciona:**
- Assume que já decidiu
- Escolha é sobre timing, não sobre decisão
- Cria compromisso concreto

---

#### 21. "Há Alguma Razão Para Não Começar?" 🚫

**Quando usar:** Para identificar última barreira.

**Script:**
```
"Pelo que conversámos, parece que faz sentido.

Há alguma razão específica para não começarmos hoje?"
```

**Por que funciona:**
- Direto, mas não agressivo
- Revela última objeção oculta
- Podes resolver na hora

---

#### 22. "Vamos Fazer o Seguinte..." 🤝

**Quando usar:** Para proposta de meio-termo.

**Script:**
```
"Vamos fazer o seguinte:

Começamos com [projeto menor/trial de 15 dias].
Vês resultados, ganhas confiança.

Se fizer sentido, escalamos.
Se não fizer, pelo menos tentámos.

Faz sentido?"
```

**Por que funciona:**
- Reduz risco percebido
- Cria porta de entrada
- Cliente sente que tem saída

---

#### 23. "Só Tenho X Vagas" 📆

**Quando usar:** Para criar urgência real.

**Script:**
```
"Sendo transparente: só tenho [2] vagas este mês

porque estou com [onboardings em curso].

Se faz sentido para ti, querias garantir uma
antes de fecharmos?"
```

**Por que funciona:**
- Escassez real, não falsa
- Cria motivo para decidir agora
- Mostra que és procurado

---

#### 24. "O Que Precisas Para Decidir?" 🎯

**Quando usar:** Quando cliente está indeciso.

**Script:**
```
"Entendo que é uma decisão importante.

Para eu te ajudar: o que precisas para tomar uma decisão?

É mais informação? É falar com alguém? É outra coisa?"
```

**Por que funciona:**
- Mostra que queres ajudar, não pressionar
- Revela obstáculo real
- Podes remover obstáculo

---

#### 25. "Resumindo..." 📝

**Quando usar:** No final, para confirmar e fechar.

**Script:**
```
"Deixa eu resumir para ter certeza que estamos alinhados:

- Queres [resultado]
- O problema atual é [X]
- A solução é [Y]
- Investimento é [€Z]
- Começamos em [data]

Faz sentido? Há algo que esqueci?"
```

**Por que funciona:**
- Confirma alinhamento
- Último "sim" antes de compromisso
- Evita mal-entendidos

## 🎯 COMO USAR GANCHOS (SEM PARECER ROBOTIZADO)

### Regra 1: Adapta ao Teu Tom
```
Não decore scripts palavra por palavra.

Pega a ideia e fala com as TUAS palavras.

Se soares natural, o cliente não percebe que é "técnica".
```

### Regra 2: Timing É Tudo
```
Gancho errado na hora certa = falha
Gancho certo na hora errada = falha
Gancho certo na hora certa = fecho
```

### Regra 3: Pratica em Voz Alta
```
Lê os scripts em voz alta 10x.

Depois grava-te a falar.

Ouve e ajusta até soar natural.
```

---

## ⚠️ ERROS COMUNS COM GANCHOS

| Erro | Por Que É Mau | Como Evitar |
|------|---------------|-------------|
| Decorar sem entender | Soa robótico | Entende o princípio por trás |
| Usar fora de contexto | Não funciona | Aprende quando usar cada um |
| Usar demasiados | Parece manipulação | 1-2 ganchos por call é suficiente |
| Não adaptar ao cliente | Não ressoa | Ajusta linguagem ao perfil |
| Interromper cliente | Quebra rapport | Espera cliente terminar sempre |
