## 📧 E-MAILS DE SEQUÊNCIA (21 Dias)

### E-mail 1 — Inicial (Dia 1)

**Assunto:** [Nome da empresa] + [Resultado específico]

```
Oi [Nome],

Vi que a [Empresa] [insight específico sobre a empresa].

Trabalho com [nichos similares] e ajudamos empresas como a tua
a [resultado concreto em números].

Faz sentido conversarmos 10 minutos sobre como [benefício específico]?

[Teu nome]
[Teu site/LinkedIn]
```

**Variação para stands:**
```
Assunto: [Nome do Stand] — ideia para vender mais 3 carros/mês

Oi [Nome],

Vi que o [Nome do Stand] tem um stock interessante de [marca/modelo].

Trabalho com stands de automóveis e ajudamos a vender mais 3-5 carros/mês
através de conteúdo estratégico nas redes sociais.

Faz sentido conversarmos 10 minutos?

[Teu nome]
```

### E-mail 3 — Follow-up #2 (Dia 5)

**Assunto:** [Nome], uma ideia rápida

```

Tive uma ideia para a [Empresa] enquanto analisava [situação específica].

Basicamente: [insight em 1-2 frases].

Se fizer sentido, posso partilhar mais detalhes numa call de 10 min.

[Teu nome]
```

**Exemplo preenchido:**
```

Basicamente: os vossos vídeos estão a chegar a 500 pessoas.

pessoas da vossa região.

Se fizer sentido, posso partilhar mais detalhes numa call de 10 min.

[Teu nome]
```

## 📞 WARM CALL SCRIPT (Dia 21)

### Abertura

```
"Olá [Nome], sou [teu nome] da [empresa].

Tenho tentado contactar-te nas últimas semanas
por e-mail e LinkedIn sobre [resultado específico].

Faz sentido conversarmos 10 minutos?"
```

**Se disser "Sim":**
```
"Perfeito! Vou ser direto:

Trabalho com [nichos similares] e ajudamos empresas como a tua
a [resultado em números].

Basicamente, [explicação em 1 frase].

O que me dizes de agendarmos uma call de 30 minutos
para eu entender melhor o teu negócio e ver se faz sentido?"
```

**Se disser "Não" / "Estou ocupado":**
```
"Sem problemas! Preferes que envie um e-mail
com mais informações primeiro?

Ou há uma altura melhor para falarmos?"
```

**Se disser "Manda informação":**
```
"Claro! Mando-te um e-mail ainda hoje com:
- Case studies de empresas similares
- Como trabalhamos
- Resultados típicos

Depois vês se faz sentido e falamos.
Qual é o teu melhor e-mail?"
```

## 📅 AGENDAMENTO DE REUNIÃO

### Quando a Lead Aceita a Call

```
"Perfeito! Aqui está o link para agendares:

[Link Calendly/Google Calendar]

Tenho horários [X] e [Y] esta semana.
Qual funciona melhor para ti?"
```

### Confirmação Imediata (Após Agendamento)

**Assunto:** Confirmado: [Data/Hora] — [Teu Nome] + [Nome da Lead]

```
Oi [Nome],

Obrigado por agendares! Aqui estão os detalhes:

📅 Data: [Dia, Hora]
📍 Local: [Link Zoom/Google Meet]
⏱️ Duração: 30 minutos

O que vamos cobrir:
- Entender o teu negócio e objetivos
- Identificar bloqueios atuais
- Ver se faz sentido trabalharmos juntos

Para prepararmos melhor:
- Website da empresa
- Principal desafio atual com [X]

Se precisares reagendar, responde a este e-mail.

Até [dia da reunião]!

[Teu nome]
```

## 🔄 FOLLOW-UP PÓS-REUNIÃO

### E-mail de Agradecimento (15 min após reunião)

**Assunto:** Obrigado + Próximos passos

```
Oi [Nome],

Obrigado pelo tempo hoje!

Como combinado, aqui está [o que prometeste enviar]:
- [Link para proposta]
- [Case study]
- [Outro material]

Próximos passos:
1. [O que tu vais fazer]
2. [O que a lead vai fazer]
3. [Deadline/check-in seguinte]

Qualquer dúvida, estou por aqui.

[Teu nome]
```

### Follow-up #1 (2 dias após reunião)

**Assunto:** Check-in rápido

```
Oi [Nome],

Só a fazer um check-in rápido após a nossa reunião.

Conseguiste [ação que a lead ia fazer]?

Alguma dúvida que tenha surgido?

[Teu nome]
```

### Follow-up #2 (5 dias após reunião)

**Assunto:** [Nome], ainda faz sentido?

```
[Nome],

Imagino que estejas busy.

Só a confirmar se ainda faz sentido avançarmos com [X].

Se a prioridade mudou, sem problemas — é só me dizeres.

[Teu nome]
```

### Follow-up #3 — Breakup (10 dias após reunião)

**Assunto:** Fechar o ciclo

```
[Nome],

Tenho tentado contactar-te sobre [projeto/proposta].

Imagino que:
- Não seja prioridade agora, OU
- Já resolveram internamente, OU
- Estás sobrecarregado/a

Vou fechar o follow-up por aqui para não ser invasivo.

Se no futuro fizer sentido, estou por aqui.

Todo o sucesso!

[Teu nome]
```
