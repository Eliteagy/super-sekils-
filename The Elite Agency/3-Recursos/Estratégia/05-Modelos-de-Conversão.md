# Modelos de Conversão: One Call Close vs Two Call Close

**Categoria:** #vendas #conversão #processo
**Nível:** Avançado

---

## 💡 Ideia Principal

> **Antes de desenhar um processo de vendas profissional, é obrigatório escolher o modelo operacional.**

**Ambos funcionam, ambos podem ser otimizados, mas servem objetivos diferentes.**

---

## 🎯 Visão Geral

| Modelo | Quando Usar | Taxa de Fecho | Ciclo de Venda |
|--------|-------------|---------------|----------------|
| **One Call Close (OCC)** | Leads quentes, tickets baixos | 20-40% | 1-3 dias |
| **Two Call Close (TCC)** | Tickets €5.000+, outbound | 30-50% | 3-7 dias |

**A escolha do modelo define:**
- A duração das reuniões
- A previsibilidade da taxa de fecho
- O esforço emocional do vendedor
- O perfil ideal de cliente
- A velocidade da pipeline
- A forma de treinar equipas

> **Não existe "melhor ou pior". Existe adequação ao contexto, ao ticket e à maturidade do negócio.**

---

## 📊 ONE CALL CLOSE (OCC)

### Vender tudo numa só conversa.

---

### Vantagens do OCC

| Vantagem | Descrição |
|----------|-----------|
| **1. Velocidade** | A lead entra → faz call → toma decisão. Ciclo de 1-3 dias. |
| **2. Excelente para leads quentes** | Inbound, referrals, pessoas pré-convencidas. |
| **3. Alta eficiência quando lead está 90% decidida** | Segunda call apenas atrasa decisão óbvia. |
| **4. Menos follow-up operacional** | Menos agendamentos, menos fricção. |
| **5. Limpa o pipeline rapidamente** | Descobres de uma vez quem avança. |

---

### Desvantagens do OCC

| Desvantagem | Descrição |
|-------------|-----------|
| **1. Difícil de escalar em equipa** | Depende demasiado do talento individual. |
| **2. Exige habilidades elevadas** | Diagnóstico + Tensão + Solução + Objeções + Fecho — tudo numa call. |
| **3. Calls longas e desgastantes** | 50-75 minutos. Cliente e vendedor cansados. |
| **4. Mais pressão emocional** | Se não converte, não há segunda oportunidade. |
| **5. Taxa de fecho mais baixa para tickets altos** | €5.000-€10.000 exige mais tempo de decisão. |

---

### Quando Usar OCC

- ✅ Leads inbound quentes
- ✅ Referrals
- ✅ Reativações com urgência
- ✅ Pequenas ofertas, tickets baixos
- ✅ Cliente já te segue há meses
- ✅ Enviaste conteúdo pré-call muito forte

---

### Estrutura Completa do OCC

#### PRÉ-CALL (Preparar o Terreno)

**1. Mensagem de Confirmação (Imediata)**
```
"Confirmado para hoje às X.
Vai ser uma sessão curta e direta: faço-te algumas perguntas
sobre a situação atual e, se fizer sentido, mostro-te como trabalhamos.
Até já."
```

**2. Envio de Prova Social**
- Case studies
- Screenshots de resultados
- Testemunhos

**3. Pergunta de Enquadramento**
```
"Para aproveitarmos ao máximo: qual é hoje o teu maior desafio?"
```

**4. Apresentar Estrutura da Call**
```
1. Entender contexto
2. Diagnosticar o que está a travar
3. Mostrar solução
4. Alinhar próximos passos
```

---

#### A CALL (Estrutura Oficial)

**1. Abertura (2 min)**
```
"Obrigado por teres marcado. Esta call dura cerca de 30 minutos.
Vou fazer-te primeiro algumas perguntas para perceber a tua situação
e depois, se fizer sentido, explico como trabalhamos e os próximos passos.
Parece-te bem?"
```

**2. Diagnóstico (15-20 min)**

**Perguntas Obrigatórias:**
- "Onde estás agora em [área relevante]?"
- "O que te fez procurar ajuda agora?"
- "O que está a funcionar bem?"
- "E o que não está?"
- "Que impacto concreto isto está a ter?"
- "O que já tentaste que não funcionou?"
- "O que acontece se nada mudar nos próximos 2-3 meses?"

**As 2 Perguntas de Ouro:**
- "Porquê agora?"
- "Quanto custa este problema neste momento?"

**Regra:**
> **A lead deve falar 70%. Tu só guias. Zero pitch nesta fase.**

---

**3. Transição para Apresentação**
```
"Com base no que disseste, faz sentido eu explicar o que faríamos no teu caso?"
```

**4. Apresentação da Oferta (5-7 min)**

**Estrutura:**
- Segmento
- Outcome
- Mecanismo
- Prova
- Condições

**Exemplo:**
```
"Trabalhamos com agências entre 10-50 pessoas que querem estruturar
o departamento comercial sem aumentar headcount.

O que fazemos é [mecanismo].

Já aplicámos isto em 40+ agências [prova].

O investimento é X com compromisso de 3 meses [condições]."
```

---

**5. Time-to-Value**
```
"Nas primeiras 2 semanas vais ter X e Y implementado,
o que normalmente já desbloqueia Z."
```

**6. Fecho Natural**
```
"Isto parece-te alinhado com o que procuras?"

Se sim: "Queres que te explique como seria começarmos esta semana?"
Se hesitação: Gerir objeção
```

---

**7. Objeções (Fórmula C.A.L.M.)**

| Letra | Ação | Exemplo |
|-------|------|---------|
| **C** | Clarificar | "Quando dizes que é elevado, é em relação a quê?" |
| **A** | Acolher | "Percebo perfeitamente, muitos sentiram o mesmo." |
| **L** | Levar ao diagnóstico | "Diz-me: quanto te custa este problema por mês?" |
| **M** | Mostrar alinhamento | "Então o investimento é inferior ao custo de continuar assim." |

---

#### PÓS-CALL E DECISÃO

**1. Envio de Proposta (Mesmo Dia)**
- Resumo da oferta
- Preço
- Condições
- Primeiros passos
- Link de pagamento ou contrato
- Data sugerida para onboarding

**2. Mensagem de Pós-Call**
```
"Gostei muito da conversa. Tens tudo para ter resultados rápidos,
principalmente porque já tens clareza sobre a dor e estás no timing certo.
Fico a aguardar a tua decisão para começarmos."
```

**3. Follow-Up Estruturado**

| Dia | Mensagem |
|-----|----------|
| 1 | "Alguma dúvida que te esteja a travar?" |
| 2 | "Queres que ajuste a proposta a algum contexto específico?" |
| 4 | "Se quiseres, fechamos só o onboarding e começamos para a semana." |
| 7 | "Vou dar esta oportunidade por concluída. Se fizer sentido no futuro, reabrimos." |

**4. Reativação a 90 Dias**
```
"Três meses depois, como está a situação com X?
Vale a pena voltarmos a falar?"
```

## 📊 TWO CALL CLOSE (TCC)

### Duas chamadas: uma para QUALIFICAR, outra para VENDER.

> **O modelo mais previsível, replicável e escalável para agências B2B.**

---

### Vantagens do TCC

| Vantagem | Descrição |
|----------|-----------|
| **1. Aumenta drasticamente a taxa de fecho** | Divides: Diagnóstico → Venda |
| **2. Filtra leads fracas antes de gastar tempo** | Só levas para Call 2 quem tem fit |
| **3. Conversas mais curtas e objetivas** | Discovery: 45-60 min, Closing: 30-45 min |
| **4. Melhor experiência para o cliente** | Sem pressão. Estrutura e disciplina. |
| **5. Equipa aprende mais facilmente** | Processo dividido em partes simples |
| **6. Oportunidade de criar "pull" entre calls** | Envias cases, áudios, PDFs |
| **7. Pipeline mais limpa e previsível** | 50 calls = 30 qualificados = 5-8 fechos |

---

### Desvantagens do TCC

| Desvantagem | Descrição |
|-------------|-----------|
| **1. Ciclo de venda maior** | 1-3 dias → 3-7 dias |
| **2. Requer boa logística de follow-up** | Manter lead viva entre Call 1 e 2 |
| **3. Mais dependência de calendário** | Encontrar horários para 2 calls × 2 pessoas |
| **4. Se Call 1 for fraca, Call 2 morre** | Qualificação fraca = venda fraca |

---

### Quando Usar TCC

- ✅ Tickets de €5.000+
- ✅ Consultoria
- ✅ Agências com múltiplos serviços
- ✅ Vendas B2B com vários decisores
- ✅ Leads de outbound
- ✅ Funis longos
- ✅ Serviços que exigem confiança
- ✅ Queres escalar processo para equipa

---

### Estrutura Completa do TCC

#### CALL 1 - QUALIFICAÇÃO (45-60 min)

**Objetivo:** Filtrar, diagnosticar e confirmar se vale a pena avançar.

**1. Abertura (2 min)**
```
"Obrigado pelo teu tempo. Esta call é breve:
vamos conversar para perceber onde estás, o que te está a travar
e se faz sentido aprofundarmos numa segunda sessão mais estratégica.
Faz sentido para ti?"
```

**2. Diagnóstico Leve (15-20 min)**

**Perguntas-Chave:**
- "Onde estás agora em [área relevante]?"
- "O que te fez procurar ajuda agora?"
- "O que está a funcionar bem?"
- "E o que não está?"
- "Quais foram as tentativas anteriores?"

---

**3. Avaliar FIT (4 Dimensões)**

| Dimensão | Pergunta |
|----------|----------|
| **Dor real** | Sem dor, não há venda |
| **Capacidade** | Tem equipa? Recursos? Maturidade? |
| **Autoridade** | É decisor? Quem mais decide? |
| **Timing** | "Porquê agora?" "Qual é a urgência?" |

---

**4. Red Flags (NÃO marcar Call 2 se 2+ aparecem)**

- "Estamos só a explorar."
- "Não temos budget definido."
- "O sócio não está alinhado."
- "Não temos muita urgência."
- Linguagem vaga: "vamos ver, estamos a analisar."

---

**5. Criar Open Loop**
```
"Com o que me disseste, é claro que existem aqui 2-3 bloqueios
estruturais que podemos resolver rapidamente.
Prefiro mostrar-te isso com calma numa sessão própria."
```

**6. Agendar Call 2**
```
"Vamos marcar uma sessão estratégica de 45-60 minutos para eu te mostrar
exatamente como resolvemos este tipo de casos.
Quinta às 15h funciona?"
```

---

#### ENTRE CALL 1 E CALL 2 (Warm-Up)

> **Esta fase aumenta a taxa de fecho 20-40%.**

**O que enviar:**

1. **Resumo do Diagnóstico**
   ```
   "Aqui estão os 3 pontos principais que identifiquei hoje:
   - X
   - Y
   - Z"
   ```

2. **Casos Práticos Relevantes**
   - Mostrar que já fizeste isto para alguém igual

3. **Preparação Mental para Investimento**
   ```
   "Na sessão estratégica também te explico o investimento e os termos,
   para decidirmos de forma clara se faz sentido avançar."
   ```

4. **Garantir Decisores**
   ```
   "Consegues trazer o teu sócio/gestor para a sessão de quinta?
   É importante que todos os decisores estejam presentes."
   ```

---

#### CALL 2 - VENDA (30-45 min)

**1. Abertura (2 min)**
```
"Antes de começarmos, deixa-me confirmar se o resumo que enviei
reflete o que discutimos."
```

**2. Diagnóstico Profundo (15-20 min)**

**Perguntas de Tensão:**
- "Quanto custa este problema neste momento?"
- "O que está a acontecer por causa disto?"
- "Porque é que é crítico resolver agora?"
- "O que acontece se nada mudar nos próximos 3 meses?"

---

**3. Transição**
```
"Faz sentido eu explicar agora exatamente o que faríamos para resolver isto?"
```

**4. Apresentação da Oferta (10 min)**

**Estrutura:**
- Segmento
- Outcome
- Mecanismo
- Prova
- Condições
- Time-to-value

---

**5. Fecho Natural**
```
"Como é que isto soa para ti?"

Se positivo: "Queres que te explique como seria começarmos esta semana?"
```

**6. Objeções (C.A.L.M.)**
- Mesmo sistema do OCC

---

#### PÓS-CALL 2

**1. Envio de Proposta (Mesmo Dia)**
- Resumo
- Condições
- Preço
- Onboarding
- Responsabilidades de cada parte
- Data sugerida para início

**2. Mensagem de Pós-Call**
```
"Gostei muito da sessão. Tens um caminho claro para resolver isto
e o timing é perfeito. Fico a aguardar a tua decisão para avançarmos."
```

**3. Follow-Up Estruturado**

| Dia | Mensagem |
|-----|----------|
| 1 | "Alguma dúvida que te esteja a travar?" |
| 3 | "Queres que ajustemos algo no formato?" |
| 5 | "Se quiseres, avançamos só com onboarding." |
| 7 | "Fecho este ciclo por agora. Se te fizer sentido no futuro, retomamos." |

**4. Reativação a 90 Dias**
```
"Passaram 3 meses, como está a situação com X?
Vale a pena voltarmos a falar?"
```
