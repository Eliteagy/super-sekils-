# 🛸 Cursor Skills Index

Cursor é o editor de IA que mais cresce, e estas skills (regras e padrões) ajudam o modelo a entender melhor o seu projeto e a agir como um engenheiro experiente.

## 🚀 Core Skills (Reasoning & Analysis)

*   🔗 [[Skill - Analyze Project]] — Analisador forense de sessões de código para identificação de root causes.
*   🔗 [[Skill - Architect Review]] — Revisão especializada de arquitetura de software moderna.
*   🔗 [[Skill - Brainstorming]] — Ferramenta de raciocínio disciplinado para validação de conceitos técnicos.
*   🔗 [[Skill - Autonomous Agent Patterns]] — Padrões para construção de agentes que codificam sozinhos.

---

## 🛠️ Integações & Best Practices

*   🔗 [[Skill - Composio]] — Conectando o Cursor a 1000+ ferramentas externas (Slack, Jira, etc).
*   🔗 [[Skill - Stripe & Supabase Patterns]] — Padrões oficiais para pagamentos e bases de dados.
*   🔗 [[Skill - Courier Notifications]] — Gestão de notificações multicanal via IA.

---

## 🏗️ Como Ativar no Cursor
1. Abra o arquivo `.cursorrules` no seu projeto.
2. Copie o conteúdo destas skills conforme a necessidade do projeto atual.
3. Use o comando `@Codebase` para dar contexto completo ao Cursor.

> [!TIP]
> Combine a skill de **Analyze Project** com a de **Architect Review** para garantir que o seu projeto não só funciona, mas segue os melhores padrões de mercado.
