# 🟢 Skill - Brainstorming (Technical Ideation)

Esta skill transforma o Cursor numa ferramenta de raciocínio disciplinado para validar conceitos técnicos e designs de funcionalidades.

## 🚀 O que faz?
Ao ser ativada, a IA atua como um parceiro de pensamento crítico que ajuda a refinar ideias vagas:
- **Disciplined Reasoning**: Questiona premissas, sugere alternativas e identifica falhas lógicas.
- **Concept Validation**: Verifica se a ideia é tecnicamente viável no stack atual.
- **Design Alternatives**: Oferece 3-5 formas diferentes de abordar o mesmo problema.
- **Edge Case Identification**: Antecipa situações onde a ideia pode falhar.

## 🛠️ Como Implementar no Cursor

```markdown
# Disciplined Reasoning & Brainstorming

1. Analyze user raw idea and identify key technical requirements.
2. Formulate 3 distinct implementation strategies.
3. Compare strategies for performance, complexity and maintenance.
4. Finalize the validated design with a high-level roadmap.
```

## 📈 Vantagens
- **Decisões Informadas**: Evita começar a codificar a primeira solução que vem à cabeça.
- **Inovação**: A IA sugere padrões que o desenvolvedor pode não conhecer.
- **Consenso Técnico**: Útil para alinhar pensamentos antes de apresentar uma proposta à equipa.

> [!TIP]
> Use esta skill na fase de "rabisco" do projeto, antes de escrever a primeira linha de código, para economizar horas de refactor futuro.
