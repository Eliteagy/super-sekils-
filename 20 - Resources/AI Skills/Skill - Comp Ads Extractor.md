# Skill: Competitive Ads Extractor

> **Análise de anúncios de concorrentes (FB, LinkedIn, etc).**

## O que faz?
1. **Extração:** Scrape de Ad Libraries (Facebook, LinkedIn).
2. **Análise de Messaging:** Identifica problemas que o concorrente está a tentar resolver.
3. **Creative Patterns:** Estuda se usam vídeo, imagens estáticas, split-screen, etc.
4. **Copy Formulas:** Analisa headlines e CTAs que convertem.

## Framework de Análise
- **Pain Points:** Que dores estão a destacar? (ex: "Perda de tempo", "Custo alto").
- **Social Proof:** Usam logótipos de clientes ou números ("20M utilizadores")?
- **Hooks:** Qual a primeira frase que prende o utilizador?

## Como Aplicar
- **Identificar Gaps:** Se todos os concorrentes focam em "Preço", foca em "Qualidade".
- **Visual Meta-analysis:** Se a maioria usa UI real (screenshots), o mercado prefere transparência.
